本书：《长三角高校大学生就业和职业发展困境、成因及解决对策研究》，蔡鑫宇著。
视角：高校分管学生工作的团委书记＝研究者。全书突出江苏、浙江，沪皖为参照系。
动笔前必读：`AGENTSPEC.md`（体例铁律）、`DESIGN.md`（骨架与章目标）、
`data/RESULTS_SPEC.md`（全部实证数字）、`data/facts.md`（全部公开事实）、
`data/figures_manifest.md`（本章图件与编号）。

## 1. 交付物：content_chNN.py

```python
# -*- coding: utf-8 -*-
"""第N章 章名"""
from content_helpers import R, cell, coef, pct, F, sig, se_of
from references import c, cc

def blocks():
    B = []
    B.append({'h1': '第N章 章名'})
    B.append({'p': '……正文……'})
    return B
```

块类型（docxbuilder.build 的全部合法键）：
- `{'h1'}` 章题「第N章 空格 章名」；`{'h2'}` 节「第N节 空格 节名」；`{'h3'}` 目「一、」「二、」；
  `{'h4'}`「（一）」（少用）。
- `{'p': 文本}` 正文段（首行缩进两字符）；`{'lead': 文本}` 无缩进说明段（仅公式 where 段等）。
- `{'eq': latex, 'num': 'N-K'}` 展示公式，OMML 居中、编号右对齐。行内数学禁 LaTeX，用
  Unicode（β、R²、−0.345）。
- `{'fig': 'figs/figN_M.png', 'caption': '图N.M 图名', 'width_cm': 13.0, 'note': 或省略}`
- `{'table': {'caption': '表N.M 表名', 'header': [...], 'rows': [[...]], 'note': 或省略,
   'col_align': 或省略}}`（三线表；估计表单元格用 content_helpers.cell()）
- `{'items': [...]}` 列表（能写成段落就不用列表）。

## 2. 铁律（违者返工）

1. **一切数字**只能来自 `R`（results.json，用 f-string 引 `R['...']` 或 RESULTS_SPEC 抄录值）
   或 `data/facts.md`。禁止出现二者之外的任何统计数字；不确定就不写数字改写定性。
2. **引用**：文中一律 `c('key')`（自动登记编号）或合引 `cc('k1','k2')`（自动按年升序）。
   句法嵌入用 `c('key', paren=False)`：如 f"{c('becker1993', paren=False)}提出……"。
   只允许使用 references.py 已有的 key；不得杜撰文献。每章 8—20 处引注，前两章密、
   实证章疏、对策章中。
3. **引号**：禁「」『』。中文引号“”‘’仅用于：直接引语、政策专有提法与口号（“先就业后择业”
   “慢就业”首现）、反语非字面义、自造概念首现。普通强调不加引号；标准名/文件名用《》。
4. **术语全书统一**（RESULTS_SPEC 术语表为准）：毕业去向落实率（不写就业率）、就业满意度、
   期望落差、错配指数、体制内偏好、慢就业。首现给全称＋（英文, 缩写），其后只用简称。
5. **先文后图表**：图表必须先在正文以「见图N.M」「见表N.M」提及，图表紧随其后（图号表号用 N.M，公式编号用 N-K）；
   图名在下表名在上（builder 已处理，勿在正文重复图名）。按 figures_manifest 使用本章图件，
   不得增删编号。
6. **负号** U+2212（−0.345），页码范围与年份区间用连字符/一字线不受影响。
7. **图表注宁缺勿滥**：数据来源正文已交代则不设注；概念图不写“资料来源：作者绘制”。
   调查数据口径注一次即可：注明“数据来源：课题组 2025 年长三角高校毕业生就业调查
   （N=3846）”仅在每章首个用该数据的表。
8. **团委书记视角**（AGENTSPEC 规则 19）：每章至少一处从学生工作一线观察切入
   （谈心谈话、就业帮扶台账、访企拓岗随行、招聘会现场），对策落到组织化抓手
   （团支部、社会实践、青年之家、职业导师），但不堆砌团言团语；学术文体为主。
9. 模型/产品用抽象类别名（如“头部生成式人工智能平台”），不挂靠具体商业产品名。
10. 章字数目标见 DESIGN.md 第三节表（中文字符含标点，count_chars 口径），
    允许 ±10%；宁多勿少。

## 3. 文风

- 学术专著文体：论证充分、句子完整、段落 150—350 字，避免公文腔与排比口号。
- 每节自然衔接，节首不写“本节将……”套话；章末小结段（不设“小结”标题的章除外，
  见 DESIGN 各章说明）。
- 数据解读要写出经济含义与量级感（“相当于……”“约合……”），不是报数。
- 与前后章呼应：成因章回指现状章的典型事实，对策章回指成因章的机制。
