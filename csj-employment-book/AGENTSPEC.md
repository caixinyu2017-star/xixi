# 专著章节撰写规范（供撰写代理严格遵守）

**书名**：《长三角高校大学生就业和职业发展困境、成因及解决对策研究》 作者：蔡鑫宇
你的任务：撰写指定章节的 `content_chNN.py`，定义 `def blocks():` 返回 block 字典列表。

## 必读文件（用 Read 工具先读，全部在 csj-employment-book/ 目录）
- `DESIGN.md`：核心概念、符号约定、你所在章的内容要点与图表清单（**必须与之一致**）。
- `../ai-talent-book/content_ch07.py`：格式与文风样板（模仿其密度、学术性、推导衔接；主题不同勿抄内容）。
- `content_helpers.py`：可用辅助（c, cc, R, F, cell, coef, pct 等）。
- `data/refkeys.txt`：**唯一允许使用的参考文献 key 列表**。
- `data/facts.md`：已核实的真实宏观数据与政策时间线（宏观数字只能取自这里）。
- `data/results.json`：全部模型估计/模拟结果（经 `content_helpers.R` 访问；模型数字只能取自这里，键结构见 data/RESULTS_SPEC.md）。
- `data/figures_manifest.md`：你章节分配到的图（文件名、图名、note 要点）。

## 硬性要求
1. **字数**：本章正文中文字数（含标点）不少于分配目标。宁多勿少；充实有据，严禁注水。
2. **文风**：中文经济学/教育经济学专著风格（《经济研究》《教育研究》《中国工业经济》水准）；观点—证据—文献三位一体；全部中文全角标点；数字与英文字母半角。
3. **引用**：`c('key')`→（作者，年）；多篇 `cc('k1','k2')`（自动按年份升序）；句法嵌入 `c('key', paren=False)`。**只能用 refkeys.txt 中的 key**；本章 ≥14 个不同 key（第2、3、4、10 章 ≥18 个）。
4. **数字纪律**：宏观事实取 `data/facts.md`；模型数字经 `R[...]` 取自 results.json 并用 f-string 格式化，**不得手写编造**。
5. **公式**：显示公式 `{'eq': r'<LaTeX>', 'num': 'N-序'}`（章内从 1 连续）；行内 `$...$`。LaTeX 用 pandoc 可解析的 amsmath 子集（**禁用 \begin{aligned} 与 \text{中文}**）。推导完整：设定→求解/估计→性质→经济含义，公式间文字衔接。
6. **图**：`{'fig': 'figs/figN_M.png', 'caption': '图N.M  中文图名', 'width_cm': 13.5, 'note': ...（可选）}`。注（若有）排在图题下方、小五宋体、无缩进、两端对齐，与表注同格式；注文严禁写进图片内部。只能用 manifest 分配给本章的图；正文必须先提及“如图N.M所示”，图块紧随该段之后，且图后有解读。
7. **表**：`{'table': {'caption': '表N.M  中文表名', 'header': [...], 'rows': [[...]], 'note': ...（可选）, 'col_align': ['left','center',...]}}`。表名在上；估计表数值从 R 取（cell/coef 格式化）；每表正文先提及后出现、并有解读。
7b. **图表注的取舍原则（按学术惯例，宁缺勿滥）**：注只承载**正文无法承载、读者读图读表时必需**的元信息，**凡正文已交代的内容一律不再设注**。
   - **应当设注**：①数据来源／资料来源（凡承载数据的分析图与数据表必标）；②统计口径、样本范围、时间窗、单位、基期、匿名化处理等测量性说明；③显著性标记与标准误含义、样本量N、控制变量；④图中缩写或简称与正文名称的对应；⑤读图必需的符号约定与图例（如因果回路图的＋／－／R／B／∥、存量—流量图的图形语义）；⑥参数取值出处与复现信息（如“其余参数取表N.M基准值”“步长0.1、窗口60期”）。
   - **不应设注**：①复述图中要素、层次与箭头关系（正文已逐一解释）；②复述正文刚给出的结论、数值或机理；③作者自绘的纯概念框架图／流程图／结构图，若正文已完整解释其构造且无需符号说明，则**整条注删除**，不必补写“资料来源：作者绘制”；④仅为凑格式而写的空泛说明。
   - 注文务求简洁，一般不超过两三句；多条信息以分号连缀，末句为来源。
8. **排版铁律**：先文后图/表；图表编号严格按出现顺序（图N.1、图N.2…）；标题层级 `{'h1': '第N章  标题'}`（唯一，块列表第一个）、`{'h2': 'N.1  …'}`、`{'h3': 'N.1.1  …'}`；每章末设“N.x 本章小结”（≥600 字）。
9. **段落**：`{'p': '…'}`；无缩进说明段 `{'lead': '其中，…'}`；少用 `{'items': [...]}`。
10. 文件顶部 `# -*- coding: utf-8 -*-` 与 `from content_helpers import c, cc, R, F, cell, coef, pct`，除 import 与 `def blocks():` 外无执行代码。

## 版式与文字体例（2026-08 用户复核后追加，三本书一体适用；违反即返工）

11. **字体**：正文中文字体宋体、西文字体 Times New Roman，全书统一。
    实现要点在 `docxbuilder.py::_set_run_font`：`w:eastAsia` 给中文字面，
    `w:ascii`／`w:hAnsi` 一律给 Times New Roman，并且**必须设 `w:hint="eastAsia"`**——
    引号“”‘’、破折号——、省略号……在 Unicode 里属「东亚宽度＝歧义」类，
    没有 hint 时 Word 会把它们判给西文字体，排出来是半角直引号，与中文不搭。
    标题用黑体，其西文同样走 Times New Roman。

12. **表格版式**：表内所有单元格的段落**段前 0 磅、段后 0 磅、单倍行距、水平居中、
    垂直居中、首行缩进 0、snapToGrid 关闭**。`col_align`／`first_col_left` 是历史兼容
    参数，不再改变对齐方式。写表时把单元格文字写短，避免居中后折行参差。

13. **引号体例**：全书**不得出现直角引号「」『』**，一律用中文引号 “ ”／‘ ’，外双内单。
    **引号宁缺勿滥**——只在下列情形使用：直接引语／受访者原话；政策专有提法与战略口号
    （“东数西算”“十五五”“人工智能＋”“五个统一”）；反语与非字面义；本书自造概念的**首次**
    出现。核心术语、已定义过的自造术语、普通名词的强调、数量表达，一律不加引号。
    标准名／榜单名／文件名用《》，不用引号。判据：删掉引号后含义不变且不会误读，就删。

14. **术语规范**：同一概念全书只用一个学术界通行词形，不得为求文采同义换用。
    经济学术语尤须核准（网络外部性／需求价格弹性／双边市场／多边平台／复制者动态／
    规模经济／全要素生产率／交易费用／演化稳定策略／经济租金……）。
    「计量」在本书多指 measurement；凡指 econometrics 必须写全「计量经济」。
    首次出现给中文全称＋（英文全称, 缩写），其后只用简称。
    完整清单见 `data/SPEC_TEXT_REVISE.md`。

15. **图内字号**：图件按 13.5—15 cm 版心宽度印刷，**图内最小字符高度不得低于图高的
    1/28**（折算印刷字号约 ≥7.5 pt），框内留白要收紧，严禁「大框小字」。
    机制／框架类概念图（D 型）用 `gpt-image-2` 生成，规范见 `data/SPEC_FIG_REDRAW.md`；
    带真实数据的统计图（A 型）用 matplotlib 绘制并绑定 results.json。
    matplotlib 画 D 型图时须注意：印刷字号＝源字号 × 版心宽度 ÷ 画布宽度，
    画布开得越宽、印出来的字越小。

16. **表格列宽与断行**：表宽默认取满版心；列宽按内容分配——每列先按其内容（至多 5 个汉字）
    保底，余量再按最长单元格视觉宽度的 0.72 次幂分配，`w:tblLayout` 设 `fixed` 并同步改写
    `w:tblGrid/w:gridCol`（渲染器在固定布局下以 tblGrid 为准，只设 `w:tcW` 不生效）。
    单元格段落须设 `w:wordWrap w:val="0"`，否则「2006」会被拆成「200／6」。
17. **负号**：正文里的负数用真正的减号 U+2212，不用半角连字符；替换须加护栏——
    仅当前一字符不是字母数字或连字符、且后一字符是数字时才替换，
    以免误伤页码范围 13-58、日期 2026-08-13、AI-Token 等。行内公式 `$...$` 内不作替换。

18. **黑白图片（本书专有铁律）**：全书所有图片一律黑白（灰度）风格。
    A 型统计图只用黑白灰，系列区分靠线型（实／虚／点划）、标记形状、灰度深浅与
    填充图案（hatch），灰阶间距 ≥25%；D 型机制图提示词写死
    strictly black-and-white / grayscale, monochrome flat vector, no color。
    质检判据：图中任何像素 RGB 三通道近似相等（饱和度≈0）。
19. **作者视角**：作者为高校分管学生工作的团委书记。各章"困境"部分从工作一线
    观察切入（双选会、慢就业台账、辅导员谈心、访企拓岗），对策部分落到
    共青团与学工系统的组织化抓手（就业育人、社区实践计划、青年之家），
    但证据与推断一律以数据和文献为准，不得用个案代替统计。
