# 禾灵儿五维文化素养基线问卷（推荐题本）

> 用于开课第一节课，测定学生的五维**底分**。共 20 题，每个维度 4 题，
> 统一采用 5 点李克特量表。填答约 3 分钟。

## 使用说明

1. 问卷开头**必须**设置两道填空题：`学号`、`姓名`（列名就写这两个词），
   系统据此把问卷结果与平台数据关联。建议再加一题 `班级`。
2. 每题选项固定为：完全不符合 / 比较不符合 / 一般 / 比较符合 / 完全符合，
   系统分别折算为 0.00 / 0.25 / 0.50 / 0.75 / 1.00。
3. 某维度底分 = 该维度 4 道题折算值的平均数。
4. 从问卷星导出 xlsx 后，在系统里选择材料类别「五维问卷」上传即可。
5. 如果贵校沿用自己的题目，**不必改代码**：打开 `questionnaire_map.json`，
   把每道题的题干片段填成 key、维度填成 value 即可。系统也内置了语义自动归类，
   在本题本上的归类准确率为 20/20。

## 计分示例

某生文化认知 4 题依次选择「比较符合、一般、比较符合、比较不符合」，
折算为 0.75、0.50、0.75、0.25，则文化认知底分 = (0.75+0.50+0.75+0.25)/4 = **0.5625**。

此后该生在禾灵儿上的每一次课程学习、作业提交、文化对话、作品创作与智能体开发，
都会在这个底分之上按 `S = B + (1-B)(1-e^(-A/κ))` 累加，逐步逼近 1.00 但不会超过。
