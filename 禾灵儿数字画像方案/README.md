# 嘉兴大学"禾灵儿"文化智能体 2.0 —— "禾灵儿数字画像"功能建设方案

本目录是"禾灵儿数字画像"功能落地方案的完整交付物：一份可直接使用的 Word 方案，
以及可复现全部图件与文档的脚本。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `禾灵儿数字画像功能建设方案.docx` | 主交付物，25 页，含 8 幅示意图、13 张三线表、11 个 Word 原生公式 |
| `figures/` | 8 幅 300 dpi 学术风格示意图（PNG） |
| `scripts/make_figures.py` | 图件生成脚本（matplotlib + Noto Sans CJK） |
| `scripts/build_docx.py` | 文档生成脚本（python-docx） |
| `scripts/docx_helpers.py` | 中文排版辅助：字号字体、三线表、图表题注、上下标富文本 |
| `scripts/omml.py` | OMML 公式构造器，生成 Word 可编辑的原生公式 |

## 方案要点

方案回答三个核心问题：

1. **采集什么** —— 十三个栏目（文化对话、文化课程、教师工作台、智能体广场、
   智能体开发、视频生成、视频广场、PPT 制作、微智工具、智能应用、智能化评价、
   资讯中心、意见反馈）逐一给出关键行为事件、核心采集字段与支撑维度（表 3）。
2. **凭什么评** —— 文化体验、文化认知、文化志趣、文化认同、文化研创五个一级维度，
   下设 20 个二级观测点，理论依据为"知—情—意—行"四位一体与 5C 核心素养中的
   "文化理解与传承"（表 1、表 2、图 2）。
3. **怎么转成分** —— 采用 DR-NKT（双表征神经知识追踪）：TGCN 行为表征 + SOP 文化
   本体嵌入 + 交叉注意力对齐，再经时间衰减、证据饱和与向先验 0.50 的贝叶斯收缩合成
   得分（式 1—11、图 4、图 5）。综合指数核算与平台界面示例（0.81、环比 +6.6%）
   逐项对齐（表 7）。

## 排版规范

按任务要求执行：一级标题黑体小三加粗；二级标题黑体四号；三级标题黑体小四；
正文宋体小四、无段前段后间距、1.5 倍行距、首行缩进 2 字符；图题置于图下、
表题置于表上，均为五号黑体；表格一律三线表；全部图表均先在正文中引用再出现。

## 复现方式

```bash
pip install matplotlib numpy python-docx
apt-get install -y fonts-noto-cjk          # 图件中文字体

python3 scripts/make_figures.py            # 生成 figures/*.png
python3 scripts/build_docx.py              # 生成 .docx
```

文档中的目录为 Word 自动目录域，首次打开时按提示更新（或 Ctrl+A、F9）即可生成页码。

图件使用 Noto Sans CJK 渲染以保证中文字形准确；文档正文按要求指定黑体/宋体，
在安装了这两款字体的 Windows/Word 环境下呈现为规范效果。
