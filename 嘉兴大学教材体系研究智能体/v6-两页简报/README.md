# 「教材智研」建设方案 · 两页简报版（现行）

A4 两页，一张黑白架构图 + 一张经费表，正文约 1490 字。v1—v5 保留备查。

## 两处方向调整

**改为新建独立智能体**，不再在"禾灵儿"上扩建。理由：本课题所需的材料溯源、标签归位与表述比对，与"禾灵儿"面向的德育资源推送差异较大；独立建设便于语料、权限与运营自成一体，也便于结项后整体移交教务处。相应地，开发科目由 3.0 万调为 3.5 万，标注由 2.8 万调为 2.5 万，总额仍为 8.0 万。

**图改为三层结构**，回答"有什么用／怎么实现／怎么建"：
- 有什么用：溯源检索（找得到材料 条条有出处）、学术助研（看得清缺口 理得出命题）、教材评价与合规审查（评得了质量 查得出风险）
- 怎么实现：各功能下对应的材料库、标签体系、比对规则等机制
- 怎么建：搭系统 → 建材料库 → 上功能 → 交运营，含经费 8 万元

黑白、大字、少元素，外行可直接读懂。
