## 方案要点

**定位**：不新建系统，在浙江省德育教材研究基地已牵头建成的"禾灵儿"智能体平台上扩建研究模块。课题经费科目中不含软件开发费，另建平台既无预算支撑也无必要。

**边界**：助手承担材料的检索、归集、并置与计数，交付带出处的材料与统计结果；范畴界定、命题提炼、逻辑建构与结论判断由课题组完成。一条硬规则——每条材料必须挂载出处，无出处不入库、不交付。

**三库**：政策文本库、文献史料库、教材案例库。教材案例库只收书目与目录层信息，正文不入库。

**四项功能**，各自对应课题的一个研究需求：

| 功能 | 服务对象 |
|---|---|
| 范畴溯源 | 专题一　五个核心范畴的四类依据 |
| 话语转化对照 | 研究难点　政策话语向学术话语转化 |
| 八体系归位 | 专题二　体系结构与研究覆盖度 |
| 质量维度试标 | 专题三　六维度的可操作性校验 |

其中"话语转化对照"针对课题自述的首要难点：输入一条政策表述，以政策文本、学术文献、历史材料三栏并置呈现，研究者据此提炼学术命题，助手只做并置与溯源。

**进度**：不单独设置建设进度，嵌入课题五阶段研究计划，每阶段只做当阶段研究需要的部分。
