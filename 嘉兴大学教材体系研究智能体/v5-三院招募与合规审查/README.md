# 「教材智研」建设方案（现行版）

服务于教育部大中小学课程教材研究项目《中国特色高质量教材体系的基础理论研究》。
15 页，5 图 6 表。**本目录为现行版本**，v1—v4 保留备查。

## 本版改动

**1. 招募单位改为文科三院。** 标注队伍由马克思主义学院（中共党史党建学院）、教育学院、文法学院联合招募本科生与研究生。三院专业背景与材料类型对口：马院对应政策文本、党领导教材建设史料与价值标签；教育学院对应教材理论、课程论与教学性维度；文法学院对应文本表述、话语体系与规范性维度。模块开发仍委托人工智能学院团队（沿用"禾灵儿"做法），开发与标注两条线分工明确。

**2. 研究内容新增教材管理与评价、表述风险合规审查、风险管控**，对应申报书专题三"教材编写、审核、出版、选用、使用、评价、修订与风险防控的全过程治理闭环"。

**3. 三项功能重组为**：溯源检索、学术助研、教材评价与合规审查。原"归位标注"并入学术助研；表2 改写为通俗表述（做什么／给出什么／用在哪里）。

**4. 教材案例登记三个匹配维度**：学科、学段（小学至高等教育）、教育类型（普通／职业／继续教育），服务学段贯通与类型协同研究。

**5. 打标签由师生协同**：学生初标复核，带队教师现场指导标签口径，课题组确认。

**6. 保密约定**贯穿建设全过程：开发团队与标注师生均签保密承诺书，四项义务（不外传、不留副本、不转借、离岗交回），合同列明违约责任，项目结束后继续有效。

**7. 后期运营管理由学校教务处承接**：账号权限、材料更新下架、使用统计年度报告、跨部门对接；助手的教材评价与合规审查功能与教务处的教材选用审核业务直接衔接，运维支出纳入教务处日常经费。
