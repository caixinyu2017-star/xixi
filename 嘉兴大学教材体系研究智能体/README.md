## 方案要点

智能体定位为教材体系研究的数字化支撑工具，服务教材立项论证、选用审查、体系诊断、课程思政资源检索、教材史研究与课题申报。

**政策依据**：《教育强国建设规划纲要（2024—2035年）》、《普通高等学校教材管理办法》（教材〔2019〕3号）、《中国智慧教育白皮书》（2025年5月）、《教师生成式人工智能应用指引（第一版）》（2025年11月）、《生成式人工智能服务管理暂行办法》。

**五项基本原则**：育人主体地位、证据优先、体系视角、人机分工、全程留痕。

**「双枢六层」总体架构**：L0 语料与数据底座层 → L1 中国特色价值坐标层 → L2 教材体系知识图谱层 → L3 研究助研智能体群 → L4 教材体系诊断层 → L5 人机协同研究共同体层；入口的任务解析枢与出口的输出规范枢为两道治理枢纽，全过程留痕审计链为运行底盘。

**七项创新点**：任务规范化转译机制、证据原子数据契约、输出规范性检验装置、四维坐标索引、真实案例线索发现机制、三色灯人机责任分配协议、红船专题语料层。

## 排版规范

文档按以下规范排版：

| 层级 | 字体字号 |
|---|---|
| 章标题（一级） | 黑体、小三号、加粗 |
| 节标题（二级） | 黑体、四号 |
| 条标题（三级及以下） | 黑体、小四号 |
| 正文 | 宋体、小四号，无段前段后间距，1.5 倍行距，首行缩进 2 字 |
| 图名 | 五号黑体，置于图下方 |
| 表名 | 五号黑体，置于表上方 |
| 表格 | 三线表（表首粗线、表头分隔细线、表末粗线，无竖线） |

图表编号不在正文中硬写：`方案正文.md` 用 `{{fig:key}}` / `{{tbl:key}}` 作符号引用，`build_docx.js` 按文档出现顺序统一分配序号并回填，增删图表不需要手工重排编号。构建时还会校验每一幅图、每一张表均已在其出现位置之前的正文中被引用，未通过校验会在控制台报出。

## 复现构建

```bash
# 1. 生成图示（需要环境变量 CHEDANKJ_API_KEY）
python3 gen_images.py prompts2.json 图示   # 前 9 幅
python3 gen_images.py prompts3.json 图示   # 部署与访问端口图

# 2. 生成 Word（需要 node + docx）
npm install docx
node build_docx.js 输出.docx
```

目录页码由两遍构建确定：第一遍渲染 PDF 定位各级标题所在页并写入 `pages.json`，第二遍据此填入页码。目录行数在两遍之间不变，因此分页不漂移。
