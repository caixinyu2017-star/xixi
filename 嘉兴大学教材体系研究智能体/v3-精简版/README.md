## 要点

**定位**：不新建系统，在基地已建成的"禾灵儿"平台上扩建研究模块。课题经费科目中不含软件开发费。

**一库三用**：一个材料库（政策文本、文献史料、教材案例三类）+ 三项功能 + 一条规范（每条材料必须带出处）。

| 功能 | 对应申报书 |
|---|---|
| 溯源检索 | 专题一　五个核心范畴的四类依据；四种研究方法的材料准备 |
| 三栏对照 | 研究难点　政策话语向学术话语转化 |
| 归位标注 | 专题二　八个子体系结构；专题三　质量六维度 |

八体系归位与质量六维标注是同一操作（把材料贴进标好的格子看分布），合并为一项功能。

**进度**：核心功能 2026.11 前建成（六个月），全部功能 2027.05 前建成（一年），此后不再新增功能，转入常态运行。

**经费**：不另申请，在课题已有预算科目内安排。
