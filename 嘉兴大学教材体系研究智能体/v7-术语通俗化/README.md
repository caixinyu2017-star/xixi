## 本版改动：术语摊开

| 原术语 | 现写法 |
|---|---|
| 三个专题 | 分别研究教材体系"是什么""为什么""怎么做" |
| 五个核心范畴 | 逐一列出："中国特色""高质量""教材国家事权""教材体系""中国自主知识体系" |
| 四类依据 | 理论依据（学理上讲不讲得通）、历史依据（历史上怎么做的）、制度依据（现行文件怎么规定）、现实依据（当下实践什么状况） |
| 八个子体系格子 | 拆成八个部分并逐一加白话注解：价值体系（为谁培养人）、知识体系（用什么知识培养人）、话语体系（用什么方式表达）、标准体系（什么样才算高质量）、类型体系（用哪些教材培养人）、形态体系（用纸质、数字还是配套资源）、治理体系（编写审核选用怎么管）、重大专项体系（重点建哪些专项教材） |
| 六个质量维度 | 政治性（方向对不对）、科学性（知识准不准）、教学性（好不好教好不好学）、规范性（体例术语引证规不规范）、时代性（内容新不新跟没跟上实践）、原创性（是不是自主编写、用的是不是中国案例） |
| 覆盖度视图 | 自动统计每个部分现有多少条材料，哪部分长期偏少就是论证缺支撑 |
| 一致性数据 | 两人各自独立标注后比对结果的吻合程度；吻合度高说明界定清楚可操作 |
| 三栏并置 | 政策栏／学术栏／历史栏各显示什么，逐栏说明 |
| 学段、教育类型 | 括注小学、初中、高中、高等教育；普通教育、职业教育、继续教育 |

图中"怎么实现"一层也同步改为白话：建材料库收四类材料／给材料贴标签归入八个部分／按六个方面逐本标注、两人各标一遍比吻合度等。
