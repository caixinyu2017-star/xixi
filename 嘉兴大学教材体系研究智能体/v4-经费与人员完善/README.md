# 「教材智研」建设方案（现行版，含经费与人员细化）

服务于教育部大中小学课程教材研究项目《中国特色高质量教材体系的基础理论研究》。

**本目录为现行版本**，v1/v2/v3 保留备查。12 页，4 图 5 表。

## 本版新增：第六章 经费与人员

在用户修订版基础上重写，去掉"不另申请经费"的口径。

**6.1 经费来源与预算** —— 向学校申请专项经费 8 万元，与课题 20 万元资助经费分账管理。

| 科目 | 金额（万元） |
|---|---|
| 模块开发服务费 | 3.0 |
| 标注组织与劳务费 | 2.8 |
| 专家咨询费 | 1.0 |
| 资料征集与数字化 | 0.8 |
| 其他费用 | 0.4 |
| **合计** | **8.0** |

标注支出测算：约 2 万条材料，按类型分档、参照学校勤工助学与前期"禾灵儿"标注结算标准计酬，含带队组织与培训课时。

**6.2 组织方式** —— 沿用"禾灵儿"做法：模块开发与标注组织一并委托人工智能学院团队，学院指定带队教师负责招募、培训、任务分派与进度管理，按批次交付验收；课题组不直接管理学生个体，只负责规范制定、抽检与最终确认。

**6.3 激励机制** —— 四条：按合格件计酬（只对通过抽检与一致性检验的条数结算，单价按材料类型分档）；计入实践学时、可作大创与毕业设计选题、出具实践证明；材料汇编列名与成果致谢；老带新计酬上浮与优秀标注员评选反馈学院。配套：任务按周下达并公布进度，带队教师每两周与课题组对接。

**6.4 三级作业** —— 本科生初标 → 研究生复核 → 课题组与专家抽检确认（抽检不低于 10%，不合格整批返工）。
