# 高校毕业生职业决策调查 —— 调研包

面向中国高校毕业年级学生的一项问卷调查，研究父母生涯介入的**方式**与**多少**
对职业决策困难的不同作用。本目录是**开工前的准备件**：问卷、模拟数据、预期
结果与分析脚本，供正式发放前定稿使用。

## 数据状态（务必先读）

本目录内**没有任何真实被试数据**。`模拟数据_SIMULATED_N400.xlsx` 与
`预期结果_基于模拟数据.docx` 中的全部数值，均由 `sim/simulate.py` 按本研究所
假设的结构方程生成。

模拟数据的用途只有三个：让分析脚本在拿到真实数据之前跑通并定稿；让论文表格的
结构与变量命名提前确定；做检验力分析。它**不能**支持任何实证结论，不能写进
论文结果部分，也不能提交给期刊或数据仓储。数据既然按假设生成，它当然"支持"
假设——这既是用途，也是界限。

真实数据回收后，用同一套脚本原样重跑，以真实结果为准。

## 研究模型

- 自变量　职业决策焦虑（CA）
- 中介　　职业探索行为（CE）→ 职业决策自我效能（SE），链式
- 调节　　父母**自主支持型**生涯支持（PA）、父母**指导代办型**生涯介入（PD）、
  父母生涯参与**频率**（PF）
- 因变量　职业决策困难（CD）

中心命题：PA 与 PD 对「焦虑 → 困难」的调节方向**相反**，而常用量表只测 PF。
若如此，以往用频率类量表得到的调节结果就是两种相反效应的混合，其符号取决于
样本中两类家长的比例。

## 关键结论：400 份不够

在每个样本量下重复抽取 400 项独立研究，走完整分析流程：

| 有效样本 | 焦虑×自主支持 检出率 | 焦虑×指导代办 检出率 | 焦虑×参与频率 检出率 |
|---|---|---|---|
| 400 | 48.5% | 48.0% | 6.2% |
| 600 | 67.8% | 71.0% | 5.2% |
| 800 | 75.8% | 81.0% | 8.0% |
| 900 | 81.2% | 86.8% | 5.8% |

两个关键交互项的真实标准化系数约 0.09，是本领域常见量级。要让两者都达到 80%
的常规检出标准，需要约 **900 份有效问卷**；按 85.5% 的有效率计算，需发放约
**1053 份**。

频率一栏的检出率始终在 5% 上下（即名义显著性水平），说明它确实没有效应——
这是 H3c 的证据，而不是检验力不足。

## 目录

```
design/items.py        条目、量表、背景变量、量表来源与授权 —— 唯一来源
sim/simulate.py        模拟作答生成（结构方程 → 潜变量 → 条目 → 筛选）
analysis/stats.py      OLS、ML 验证性因子分析、信度、HTMT、Bootstrap 中介
analysis/run.py        完整分析流程；回收真实数据后原样重跑
build/                 三份交付件的生成脚本
out/                   t1–t9 表格（TSV）、summary.json、预览
```

## 复现

```
python3 analysis/run.py              # 约 2 分钟，写出 out/
python3 build/build_questionnaire.py
python3 build/build_dataset.py
python3 build/build_expected.py
```

`analysis/stats.py` 直接运行会跑自检：验证性因子分析与中介估计在已知真值的
合成数据上各自复原参数。
