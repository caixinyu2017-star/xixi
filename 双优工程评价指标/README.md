# “双优”工程关键要素梳理

面向嘉兴大学锚定“双优”（高水平应用型本科高校）建设目标的资料汇编，输出为 Word 文档。

## 产物

`“双优”工程关键要素梳理.docx` —— A4 排版，含封面、可更新目录、8 章正文、7 张表格与分类参考文献。

主要内容：

| 章节 | 内容 |
| --- | --- |
| 编制说明 | 资料的权威性分层（A 官方 / B 学术 / C 媒体 / D 整理），以及本次检索的限制 |
| 一 | 政策由来：国务院《教育发展“十五五”规划》、2026-03-07 部长记者会、三大工程定位差异 |
| 二 | “优秀办学”（论文原文作“优质办学”）十大关键要素：总表 + 逐条原文释义 |
| 三 | “优秀服务”十大关键要素：总表 + 逐条原文释义 |
| 四 | 二十个要素的转化与统一（“三个统一”）+ 配套推进的六个重要事项 |
| 五 | 学界补充框架：王洪才五维、陈文博“能力—贡献”转化效率，以及研讨会 12 位专家观点 |
| 六 | 可对标的现行评价体系：双一流成效评价、审核评估第二类、双高/新双高、苏/粤/浙/皖/鲁/川省级方案 |
| 七 | 网络检索补充与核验结论（含“200 所”口径澄清、流传图表的出处认定） |
| 八 | 对嘉兴大学的对标建议与二十要素填数自检清单 |

## 来源与可靠性

- **逐字可靠**：二十个关键要素的全部释义，逐字取自已完整读取的 4 篇论文 PDF，并经脚本回归校验（见下）。
- **检索摘要级**：所有网络来源（政策文件、省级方案、媒体解读）来自搜索引擎返回的标题、链接与摘要。
  本次编制环境的出口网关对全部外部站点返回 403（组织出口策略），无法打开网页逐字核对正文，
  文档中已逐条标注“检索摘要转述”。正式对外行文前须自行复核链接。

核心来源：瞿振元, 蔺跟荣. “双优”工程：应用型大学面对的机遇、挑战与应对[J].
中国人民大学教育学刊, 2026(4): 5-18.

## 重新生成

```bash
pip install python-docx
python3 build_docx.py
```

| 文件 | 作用 |
| --- | --- |
| `content_core.py` | 二十个关键要素的数据（论文原文逐字录入） |
| `content_web.py` | 其余各章内容（政策、对标体系、检索补充、嘉兴大学章节、参考文献） |
| `build_docx.py` | 排版与生成 |

## 校验

二十条释义与论文 PDF 的逐字一致性可回归验证：把 PDF 文本与 `content_core.py` 中的释义
都做空白与全角/半角归一，剔除 PDF 的页眉页脚（形如 `12中国人民大学教育学刊2026年`）后做子串匹配，
20 条应全部命中。
