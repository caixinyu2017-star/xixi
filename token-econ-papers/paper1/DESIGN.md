# 论文一设计：《词元价格下行与智能服务支出的背离》

**目标期刊**：《经济研究》　**作者**：蔡鑫宇（嘉兴大学经济学院）

- **中文主标题**：词元价格下行与智能服务支出的背离（17 字，≤20 字）
- **副题名**：———质量调整价格指数与回弹效应的分解
- **英文题名**：Falling Token Prices and Rising Spending on Intelligent Services:
  Quality-Adjusted Price Index and the Rebound Effect

## 一、研究问题与谜题

**观察到的悖论**：2025—2026 年，主流大模型 API 的名义词元单价大幅下行，
经济档模型的单位价格降幅可达九成以上；与此同时，企业智能服务支出不降反升，
且价格结构出现分层——经济档快速下探而旗舰档保持高位，档位间价差扩大到数十倍。

**由此产生三个待解问题**：
1. 名义降价中有多少是**真实降价**，有多少是**质量提升**被误记为降价？
2. 在正确的（质量调整后的）价格上，智能服务需求的价格弹性有多大？
   支出上升是否来自**回弹效应**（价格下降引致用量更大比例扩张）？
3. 名义价格指数低估真实成本会造成什么统计与政策后果？

**核心命题**：物理词元不是同质商品，以物理词元计价的名义价格指数系统性
**高估**了智能服务的真实降价幅度；在质量调整价格上，需求价格弹性绝对值大于 1，
价格下行通过回弹效应放大用量，从而出现「单价下降—支出上升」的背离。

## 二、边际贡献（引言第三段，三点）

1. **测度贡献**：把能源经济学「标准煤」、ICT 价格测度的享乐回归传统引入智能服务，
   构造质量调整的标准词元价格指数（STPI），并给出名义降价的三重分解：
   真实价格效应、质量效应、结构（档位替代）效应。
2. **参数贡献**：在正确价格上估计智能服务的需求价格弹性与回弹弹性，
   给出「单价下降—支出上升」背离的定量条件（|ε|>1），
   并识别任务复杂化（智能体化）对用量的独立贡献，与纯价格回弹相区分。
3. **政策贡献**：指出以名义词元价格编制的统计口径会高估人工智能带来的成本节约、
   低估真实投入，从而误导补贴核定、投资回报评估与生产率核算；给出可操作的
   编制方案与统计口径建议。

## 三、理论框架

企业在认知任务集上选择由人工完成还是由智能服务完成。智能服务的有效投入为
标准词元 $\tilde{T}=\eta T$，$\eta$ 为效值系数（由模型档位的算力强度、
推理质量、场景适配合成）。企业面对的真实价格 $\tilde{p}=p/\eta$。

- **命题 1（指数偏误）**：若质量随时间改进（$\eta$ 上升）而统计仅记录 $p$，
  则名义价格指数的下降幅度超过真实价格指数，偏误等于质量改进率。
- **命题 2（回弹）**：需求 $\tilde{T}(\tilde{p})$ 的价格弹性 $\varepsilon<-1$ 时，
  $\tilde{p}$ 下降导致支出 $\tilde{p}\tilde{T}$ 上升；本文给出 $\varepsilon$ 的可识别条件。
- **命题 3（结构分化）**：档位间纵向差异化下，经济档价格竞争激烈、旗舰档保持租金，
  加权价格指数的走势取决于档位份额迁移，故须区分固定权重与链式指数。

## 四、方法与识别

1. **享乐回归（hedonic）**：以模型档位—时期为观测单位，
   $\ln p_{mt}=\alpha_t+\mathbf{x}_{mt}'\beta+\epsilon_{mt}$，
   $\mathbf{x}$ 含能力指标、上下文长度、时延、多模态等特征；
   时期虚拟变量系数 $\alpha_t$ 即质量调整价格指数。
2. **指数编制与分解**：Laspeyres／Paasche／Fisher 与链式指数并列，
   把名义变化分解为真实价格、质量、结构三项，并做 Divisia 分解稳健性。
3. **需求弹性估计**：行业—时期面板，
   $\ln \tilde{T}_{it}=\varepsilon\ln\tilde{p}_{it}+\gamma\mathbf{z}_{it}+\mu_i+\lambda_t+u_{it}$；
   为处理价格内生性，用**成本推移工具变量**（算力硬件租金与电价的行业暴露加权，
   Bartik 式份额—移动工具）识别供给侧驱动的价格变动。
4. **回弹分解**：把支出变化分解为价格效应、纯回弹效应与任务复杂化效应，
   并做弹性异质性（行业智能化基础、企业规模）。

## 八、口径更正留档（2026-08-25，随 data_gen.py 首版实证结果一并更正）

按仓库「事实纪律」，以下五处与 `data/facts.md` 的公开锚或享乐测度的代数结论冲突，已更正，
正文须按更正后的表述撰写；`data/results.json` 与 `data/RESULTS_SPEC.md` 已按更正版生成。
第 1—3 条为首版更正，第 4—5 条为 2026-08-25 独立复核时补入。

1. **指数偏误的方向（第一节「核心命题」与第三节「命题 1」）**
   原稿：「以物理词元计价的名义价格指数系统性**高估**了智能服务的真实降价幅度」
   「名义价格指数的下降幅度超过真实价格指数」。
   **更正**：方向相反。享乐式 $\ln p_{mt}=\alpha_t+\mathbf{x}_{mt}'\beta$ 下有
   $\alpha_t=\overline{\ln p}_t-\beta'\bar{\mathbf{x}}_t$，质量 $\bar{\mathbf{x}}_t$ 改进即令
   $\alpha_t$ 比 $\overline{\ln p}_t$ 下行更快；facts.md 的质量恒定口径（2022-11 至 2024-10 降逾
   280 倍）也远快于任何挂牌均价降幅。本文实测：2023-01→2026-06 名义指数累计 −93.2%（年均 2.20 倍），
   质量调整指数 STPI 累计 −98.7%（年均 3.55 倍）。
   故正确表述为：**名义（物理词元）价格指数低估真实降价幅度，从而低估真实投入量的增长、
   低估人工智能带来的真实成本节约**；用名义指数平减会把真实投入增长记少，
   进而在生产率核算中把智能服务的贡献记少、把价格贡献记多。
   第二节「政策贡献」中「高估人工智能带来的成本节约」应改为「低估」，与「低估真实投入」一致。
   **名义口径有两个，正文不得混用**：NPI（单位价值＝支出／物理词元量，默认口径，
   2023-01→2026-06 累计 −93.248%）与 NPI_geo（支出份额加权的对数均价指数，累计 −94.224%，
   是第四节三重分解的分解对象）。引用降幅时必须点明口径。

2. **需求弹性偏误的方向（第四节第 3 点）**
   由 1 可得 $\ln p^{\text{名义}}=\ln\tilde{p}+\ln\eta$ 且 $\eta$ 上升，故以名义价格估计的
   弹性绝对值被**放大**。本文实测：双向固定效应下质量调整口径 $\varepsilon=-1.391$、
   名义口径 $-1.860$，名义口径高估 33.7%。以成本推移工具变量识别时两口径收敛
   （−1.570 与 −1.460），反证该差距确由质量与结构混入名义价格所致。

3. **档位间价差的走向（第一节）**
   原稿：「档位间价差扩大到数十倍」。facts.md 记录同一供给方旗舰档与经济档输出价比
   **约 3 倍且在调价前后稳定**。本文实测档位均价比由 2023-01 的 7.04 倍**收敛**至
   2026-06 的 3.12 倍（与 facts.md 锚对齐），只有**个体最高价／最低价**之比仍在 8—19 倍。
   故正确表述为：**档位内价格竞争把均价比压回三倍量级，而全市场个体报价的极差仍达十余倍**，
   「价差扩大到数十倍」不得写入正文。2026-07／08 的结构性提价按 facts.md 的锚
   （6→27、2→9，两档同为 4.5 倍）设为**档位间同比例**，故提价后均价比为 2.835 倍，
   仍在三倍量级；档位间与供给方间的分化来自「是否跟进提价」，不是档位本身。

4. **价格内生性的来源（第四节第 3 点补充，2026-08-25 复核时补入）**
   一稿的数据生成里价格完全由成本侧决定，工具变量无事可做，与第四节「为处理价格内生性」
   的说法不符。按 facts.md 记录的峰谷分时定价（工作日高峰翻倍、夜间与周末维持平峰），
   现已在数据生成中加入**拥塞加价**：行业自身的需求冲击经排队与分时定价进入其有效购进价格
   （传导系数 0.30）。其后果是双向固定效应 OLS 的 $|\varepsilon|$ **向零偏**——距异质斜率下
   的方差加权真值 −1.811 有 2.83 个标准误，而 2SLS 把偏误基本消掉（0.67 个标准误）。
   **但须如实报告**：Durbin–Wu–Hausman 控制函数检验的 p 值为 0.510，20 个行业的聚类稳健
   推断检验力有限，**不能拒绝价格外生**；正文不得写「内生性检验支持使用工具变量」，
   只能写「2SLS 点估计的绝对值大于固定效应 OLS，方向与拥塞加价所隐含的向零偏一致」。
   相应地，「$|\varepsilon|>1$ 在 5% 水平显著」只可依据双向固定效应估计陈述
   （单侧 p ＝ 0.0081，Wild Cluster Bootstrap p ＝ 0.015）；2SLS 口径的单侧 p 为 0.0648，
   只支持点估计的方向，不构成 5% 水平的显著性。回弹分解因此给出两套口径：
   基准（固定效应弹性）下纯回弹为**下界**，`rebound.full_iv`（2SLS 弹性）为上界，
   二者的价格通道净效应同号，「背离」的定量条件不依赖于用哪一个弹性。

5. **前沿降价的折年口径（第二节「典型事实」，2026-08-25 复核时补入）**
   facts.md 转述的斯坦福《人工智能指数报告》原文行文作「约 18 个月下降逾 280 倍」，
   但所给两个时点 2022-11 与 2024-10 实际相隔 **23 个月**；按 18 个月折年会得到
   43.4 倍／年，与报告口径不符。本文一律按时点作差折年：
   $(20.00/0.07)^{12/23}=19.11$ 倍／年。
   **正文只写时点区间（2022 年 11 月至 2024 年 10 月）与总降幅（约 286 倍），
   不复述「18 个月」这一措辞，也不据此另算年率。**
