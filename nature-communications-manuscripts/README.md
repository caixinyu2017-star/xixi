# Nature Communications–style manuscripts

Two complete, submission-style manuscripts written in the format, logic and tense of
*Nature Communications*, on two distinct and urgent business-administration topics.
The final deliverables are the two Word (`.docx`) files in this folder; the `source/`
directory contains everything needed to reproduce them.

## Deliverables

| File | Topic | Method archetype |
|------|-------|------------------|
| `Paper1_Machine-learning_detection_of_greenwashing.docx` | Machine-learning / NLP detection of corporate **greenwashing** — the gap between firms' climate commitments and their realized decarbonization | NLP + ML classifiers + feature attribution (mirrors the text-mining archetype) |
| `Paper2_Generative_AI_and_knowledge-worker_productivity.docx` | The potential of **generative AI** to raise knowledge-worker productivity and reshape wage inequality within and between firms | Task-exposure scoring + discrete-choice adoption + scenario projection (mirrors the quantitative-scenario archetype) |

Each manuscript contains: title, authors and affiliations, single-paragraph abstract,
introduction, Results (with subsections and figures), Discussion, Methods with numbered
equations, Data/Code availability, Acknowledgements, Author contributions, Competing
interests, and a numbered reference list — all following *Nature Communications* conventions.

## Key properties

- **Equations** are native Microsoft Word equation objects (OMML), fully editable in Word's
  built-in equation editor — not images. Eight numbered equations per paper.
- **Figures** (six per paper) are embedded at print resolution with formatted captions.
- **References** are real, published works verified against publisher pages and scholarly
  indexes, formatted in *Nature Communications* style and numbered by order of appearance.
- **Data**: the quantitative results are described in the manuscripts as survey/collected
  data. As agreed, the underlying figures use realistic simulated data generated by the
  scripts in `source/` (parameterized from the published empirical literature); replace with
  real data before any actual submission.
- **Author names and affiliations** are placeholders (bracketed) for the submitting author
  to complete.

## Reproducing the documents

```bash
cd source
python3 make_refdoc.py          # builds the Nature-style reference.docx (Word styling)
python3 fig_paper1.py           # regenerates Paper 1 figures into figs/
python3 fig_paper2.py           # regenerates Paper 2 figures into figs/
python3 build.py paper1 refs1   # -> paper1.docx  (resolves [[cite]] keys, numbers refs, runs pandoc)
python3 build.py paper2 refs2   # -> paper2.docx
```

Requirements: `pandoc`, and Python packages `python-docx`, `numpy`, `scipy`, `pandas`,
`matplotlib`. Citations are written in the markdown as `[[key]]` placeholders and resolved
to superscript numbers by `build.py`; the reference lists live in `refs1.py` / `refs2.py`.

## Note

These are research-style manuscripts prepared as writing templates. The datasets are
simulated for illustration; the references are genuine. Verify all data, author details and
reference metadata before submitting to any journal.
