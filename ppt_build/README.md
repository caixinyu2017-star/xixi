# 亚德客内训课件生成器

两门课的 PPTX 由脚本生成，便于后续修改内容后一键重出。

| 文件 | 说明 |
|---|---|
| `deckkit.py` | 幻灯片 XML 构建器：形状、图片、备注、软换行、字号映射 `SCALE`、断行还原 `unwrap`、自适应字号 `autofit` |
| `components.py` | 页面组件：页眉导航、侧边栏、标题、卡片、流程、横幅、情境页、团队任务页、封面、整页示意图 |
| `fixup.py` | 版面补救：把仍然装不下的文本框连同整张卡片向下方的空白处长高，长不动的交给 lint 报错 |
| `pack.py` | 复用源课件模板包（母版/版式/主题/黑板底图），替换全部幻灯片、写入备注页与图片，并回收无用部件 |
| `lint.py` | 版面检查：越界、贴边、超出内容区、文字溢出、面板遮挡、字号下限（本环境 LibreOffice 无法加载 PPTX，以此替代目视 QA） |
| `art_prompts.py` / `artfit.py` | gpt-image-2 的中文图释与英文提示词；出图后按内容区比例做边缘复制补白，不拉伸变形 |
| `validate.py` | 包结构校验：关系目标是否存在、部件有没有内容类型、幻灯片清单与磁盘是否一致 |
| `course1_*.py` / `build_c1.py` | 《个体及群体行为分析》60 页 |
| `course2_*.py` / `build_c2.py` | 《问题分析与解决》60 页 |
| `course3_*.py` / `build_c3.py` | 《价值 & 开发》60 页（营业部人员 / 中层管理者） |

重新生成：`cd ppt_build && python3 build_c1.py && python3 build_c2.py && python3 build_c3.py`
（`build_c3.py --no-art` 出全原生可编辑版本，不使用示意图）

重新出图（会产生调用费用，已生成的图在 `art/`）：

```bash
python3 /root/.claude/skills/gpt-image-2/scripts/gpt_image2.py --manifest art/prompts.json -o art/
python3 artfit.py          # 补白到 11.22" × 6.04" 的内容区比例
```

设计规范沿用源课件：13.33×7.5 英寸、微软雅黑、黑板底图、金色标题 F5D349、
米色卡片 FFF7E8、六色强调（绿/橙/蓝/红/紫/青）。

## 第二轮改版（客户意见）

1. **字号下限 18pt**。`deckkit.SCALE` 把作者标注的 11~15 号统一抬到 18pt，
   `autofit` 再按每个框的实际余量把字号和行距往上撑，撑不下时先收行距、
   绝不掉到 18pt 以下。
2. **连贯的文字不再断行**。`unwrap` 只保留结构性换行（句末标点、①②③、
   「特点：」这类带冒号的条目），句子中间的人工换行一律接回去。
3. **顶部课程名居中**，第一/二/三节导航框加宽到 4.45"/4.14"/4.14"，三个标题各占一行。
4. **情境 1~6 的「反常识做法」移到备注页**，屏幕上只留现场情境 / 讨论 / 普遍做法，
   三块放大到铺满内容区（现场情境 3.42" 高）。讲师先让学员讨论，再翻备注揭示。
5. **12 页理论页改用 gpt-image-2 生成的示意图**（见 `build_c2.ART`），
   整块铺满除框架外的内容区 2.06"/1.30" 起、11.22"×6.04"。
6. 出片前 `lint` 必须为 0：无越界、无溢出、无遮挡、字号全部 ≥ 18pt。

## 版面自检（lint）

`check(slides, coverage=True)` 逐页核对六件事：

| 检查 | 含义 |
|---|---|
| `OUT-OF-BOUNDS` / `BELOW-AREA` / `EDGE` | 越出画布、越出内容区下沿、贴边 |
| `TOO-SMALL` | 有文字低于 18pt |
| `OVERFLOW` | 文字高度超过框内可用高度（与 autofit 共用同一套行高模型） |
| `OVERLAP` | 两块实心面板互相遮挡（卡片自己的标题条除外） |
| `SPARSE` | 内容区被形状覆盖的比例低于阈值——即「大片留白」 |
| `HOLE` | 内容区里出现过高的空白横带 |

两个容易踩的坑，改代码时请留意：

1. `text()` 是**延迟渲染**的——字号在出片时才根据当时的框高决定。所以 `check()`
   必须先调用 `Slide._finalize()`，否则读到的还是占位记录，会把有问题的页判成干净。
2. 形状记录里带一个 `visible` 位。覆盖率统计只数真正有填充或描边的形状，
   纯文本辅助框不计入，否则空框会把覆盖率虚高。
