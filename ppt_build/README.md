# 亚德客内训课件生成器

两门课的 PPTX 由脚本生成，便于后续修改内容后一键重出。

| 文件 | 说明 |
|---|---|
| `deckkit.py` | 幻灯片 XML 构建器（形状、文本、软换行、字号映射 SCALE） |
| `components.py` | 页面组件：页眉导航、侧边栏、标题、卡片、流程、横幅、情景页、团队任务页、封面 |
| `pack.py` | 复用源课件模板包（母版/版式/主题/黑板底图），替换全部幻灯片并回收无用部件 |
| `lint.py` | 版面检查：越界、贴边、文字溢出、卡片重叠（本环境 LibreOffice 无法加载 PPTX，以此替代目视 QA） |
| `course1_*.py` / `build_c1.py` | 《个体及群体行为分析》60 页 |
| `course2_*.py` / `build_c2.py` | 《问题分析与解决》60 页 |

重新生成：`cd ppt_build && python3 build_c1.py && python3 build_c2.py`

设计规范沿用源课件：13.33×7.5 英寸、微软雅黑、黑板底图、金色标题 F5D349、
米色卡片 FFF7E8、六色强调（绿/橙/蓝/红/紫/青）。正文字号 16pt 起，标题 25~26pt。
