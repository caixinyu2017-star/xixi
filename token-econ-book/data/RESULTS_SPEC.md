# results.json 生成规格（data_gen.py 实现依据；锚点值不得改动）

总原则：`numpy.random.default_rng(20260813)` 固定种子；序列平滑且**精确穿过锚点**；生成后写 `data/results.json` 与 `data/series.csv`（tidy：series,x,value）并打印锚点校验。凡标注【facts】的以 `data/facts.md` 核实值为准（集中在 FACTS_SEED 区块）。

**模型命名纪律**：一律使用**档位名**而非真实产品名（避免把校准复算值挂到具体商业产品上）。六档：`light`（轻量蒸馏级）、`mid`（中型通用级，**基准档，η≡1**）、`open`（开源旗舰级）、`flag`（旗舰闭源级）、`reason`（推理增强级）、`multi`（多模态级）。

## 1. `ste`：标准词元效值折算（第5章，全书基石）
`ste: {base: 'mid', dims: {档位: {P, R, S, eta, eta_hat, eta_ces}}, weights: {wP 0.4383, wR 0.2964, wS 0.2653}, ces_rho_hat 0.0794, fit: {...}, transitivity_err, dispersion: {...}}`

**折算函数的形式与标定（第5章核心）**：
- **命题 5.1**：若折算函数 $\eta(P,R,S)$ 连续、对各维严格单调递增、满足基准归一 $\eta(1,1,1)=1$ 与链式一致 $\eta(P_1P_2,R_1R_2,S_1S_2)=\eta(P_1,R_1,S_1)\cdot\eta(P_2,R_2,S_2)$，则必为幂积形式 $\eta=P^{w_P}R^{w_R}S^{w_S}$（乘性柯西函数方程的标准结论）。
- **标定结果**：$w_P$＝0.4383、$w_R$＝0.2964、$w_S$＝0.2653（和为 1），基准任务集实测效值的拟合 $R^2$＝0.9996、对数尺度 $R^2$＝0.9997、RMSE＝0.026。
- **交叉验证**：把折算函数放宽为 CES 形式独立标定，得替代参数 $\hat{\rho}$＝**0.0794**，统计上无法拒绝 $\rho=0$——CES 恰在此处退化为加权几何平均，**实证标定与公理推论相互印证**。
- **传递一致性误差**：幂积形式下链式折算与直接折算之差为机器精度量级（＜1e-15），可加性与传递性同时成立。

## 6. `game`：平台—企业—政府三方演化博弈（第10章）
`game: {params: {cP 0.9, cF 1.0, RP 1.3, RF_base 1.5, RF_hi 2.5, s 0.6, cG 0.8, L 0.9, k0 1.0, tau_save 0.35}, threshold: {RF_crit 1.55, RF_selfsustain 1.80, x_crit 0.30}, conv: {scenA, scenB, scenC}, traj: 0—60期 RK4 dt=0.1}`
- 策略：$x$ 平台深度运营（建统一计量结算与调度）、$y$ 企业深度采纳（把词元嵌入主业务流）、$z$ 政府强激励（技改补贴＋政策抵扣）。
- 机理链条：**政府强激励→平台先行建设统一入口（交易费用节约 τ=0.35）→企业采纳收益越过阈值后跟进→采纳规模化后政府退出强激励**。
- 调整速度 $\kappa$＝1.0（RK4，dt＝0.1，窗口 60 期，初值 $(x_0,y_0,z_0)=(0.30,0.15,0.65)$）。
- **情景 A（基准 $R_F$＝1.5）**：收敛于「平台热、企业冷」——x→0.984、y→0.005、**z→0.995**（政府被锁定在强激励挡位、补贴无法退出），窗口内未完成收敛（T＝60）。
- **情景 B（$R_F$＝2.5，效值透明＋场景深化）**：x→0.995、y→0.995、**z→0.005**（补贴成功退出），T≈41.7。
- **情景 C（$R_F$＝2.5 且 $c_F$ 降至 0.7，统一接入降低企业采纳成本）**：同均衡，T≈23.5。
- **阈值（模型内生解出，不得手写）**：企业深度采纳成为演化稳定策略的临界红利 $R_F^{c}$＝**1.55**（在 x＝1、z＝0.995 处）；政府退出强激励后融合稳态自我维持的条件 $R_F$≥**1.80**。**基准红利 1.5 仅比临界值低约 3%，却导致完全不同的均衡——这一「差之毫厘」正是演化博弈阈值效应的直接体现，第9、10章须重点论证。**
