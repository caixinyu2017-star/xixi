# 正文文字规范修订 —— 引号与术语

## 0. 本轮要解决的三件事

1. **废止直角引号「」『』**：全书不得出现，一律改为中文双引号 “ ”／单引号 ‘ ’，
   或**直接去掉引号**。
2. **克制使用引号**：引号只在确有必要时使用。当前全书 800 余处引号中，
   相当一部分是无谓强调，应当去掉。
3. **经济学术语规范化**：同一概念全书用同一个学术界通行译名。

## 1. 引号取舍规则

### 1.1 应当保留（改为 “ ”）

| 情形 | 例 |
|---|---|
| 直接引语、原话引用 | 国家数据局称词元是“智能时代的价值锚点” |
| 政策文件的专有提法／战略口号 | “东数西算”“十五五”“人工智能＋”“数据要素×”“五个统一”“1+M+N” |
| 反语、比喻义、非字面义 | 出现了“平台热、企业冷”的错配 |
| 本书新造并需要标示为整体的短语，**仅首次出现时** | 首次提出“效值溢价层”这一概念时 |
| 受访者原话、访谈引述 | 一位受访企业负责人说“报价看不懂” |

### 1.2 应当去掉引号

| 情形 | 处理 |
|---|---|
| 全书核心术语（词元、标准词元、效值、词元工厂、当量折算…） | 去引号，直接用 |
| 已在正文定义过、第二次以后再出现的自造术语 | 去引号 |
| 普通名词的无谓强调（“价格”“利用率”“可比较”“首个”…） | 去引号 |
| 复述图表要素或正文结论时的强调 | 去引号 |
| 数量表达（“一千枚词元”“一次查询”） | 去引号 |

### 1.3 改用书名号《》

标准名、榜单名、规范名、文件名一律用《》而非引号：
《高质量 Token 服务标准体系》《开源模型 Token 服务性能榜》
《可信 AI-Token 服务质量评估》等。

### 1.4 嵌套

外双内单：“……‘……’……”。不得使用『』。

### 1.5 兜底判据

删掉引号后句子含义是否改变、是否会被误读？
**不变且不会误读 → 删。** 宁可少用，不可滥用。

## 2. 经济学术语规范

### 2.1 已发现的并用，须统一

| 统一为 | 废止 | 说明 |
|---|---|---|
| 网络外部性 | 网络效应 | 指未被内部化的跨边／同边外部性时一律用「网络外部性」；泛指现象且不涉外部性论证时可保留「网络效应」，但同一段内不得混用 |
| 需求价格弹性 | 需求弹性、价格弹性（单独使用时） | 首次出全称「需求的价格弹性」，其后可简称「需求价格弹性」 |
| 双边市场 / 多边平台 | 双边平台 | 「双边平台」不是通行译名 |
| 复制者动态 | 复制动态 | replicator dynamics 的通行译名 |
| 规模经济 | 规模效应（指 economies of scale 时） | 「规模效应」语义含混 |
| 资源配置效率 | 要素配置效率（指同一所指时） | 择一，全章一致 |

### 2.2 须核对的其他术语（发现不规范即改）

- 生产函数与增长核算：全要素生产率（非「全要素生产力」）、索洛残差、产出弹性、
  资本存量、要素替代弹性、技术进步、规模报酬不变。
- 产业组织：赫芬达尔—赫希曼指数（HHI）、最小有效规模（MES）、自然垄断、范围经济、
  沉没成本、进入壁垒、价格歧视（一级／二级／三级）、交叉网络外部性。
- 制度与博弈：交易费用（全书统一，勿改为「交易成本」）、激励相容、委托代理、
  信息不对称、道德风险、逆向选择、演化稳定策略、复制者动态、帕累托改进。
- 价值与价格：使用价值、交换价值、社会必要劳动时间、经济租金（勿写作「租金收益」）、
  准租金、消费者剩余、生产者剩余、机会成本、边际成本、平均成本。
- 计量与统计：变异系数、置信区间、显著性水平、稳健标准误、内生性、工具变量。
- **「计量」一词的歧义**：本书中「计量」多指 measurement（计量单位、价值计量），
  与「计量经济学（econometrics）」不同。凡指后者，必须写全「计量经济」或「计量经济学」，
  避免读者误解。

### 2.3 术语使用的一般要求

- 首次出现给出中文全称＋（英文全称, 缩写），其后一律用中文简称或缩写，不再重复全称。
- 同一概念在全书只用一个词形，不得同义换用以求文采。
- 不生造经济学术语；本书自造的概念（标准词元、效值系数、效值溢价层、场景租金层等）
  须在首次出现处给出明确定义，其后直接使用。

## 3. 不得改动的内容（红线）

- 任何数字、公式、变量符号、上下标。
- 图号、表号、式号，以及正文对它们的引称。
- 参考文献引注 `（作者，年份）` 的作者与年份，以及合引的年份升序。
- 章节标题、条标题的层级与编号。
- 图表的 caption 与 note 的既定格式。
- 全角标点体例：中文语境一律用中文标点；数字区间用「—」；不得引入半角标点。
