## 一、选题、核心命题与理论创新

### 1.1 选题依据
2026 年 3 月，全国科学技术名词审定委员会发布公告，优先推荐并面向全社会发布试用人工智能领域名词 token 的中文名「词元」；同月，国家数据局局长在中国发展高层论坛年会上提出词元具有可计量、可定价、可交易的特征，是「智能时代的价值锚点」。人工智能由模型竞争转入词元生产能力竞争：我国日均词元调用量由 2024 年初的 1000 亿枚增至 2025 年 6 月底的 30 万亿枚、2025 年底的 100 万亿枚，2026 年 3 月突破 140 万亿枚，两年增长约 1400 倍（国家数据局口径）。与此同时，苏州、嘉兴、温州、广州、上海等地在一周之内密集设立城市级词元运营中心或将词元纳入技改补贴，词元从模型服务的计价单位变为城市公共基础设施。然而，词元经济的高速扩张建立在一个未解的计量地基之上：**同样 100 枚词元，小模型与千亿参数模型的算力消耗相差十倍乃至百倍，不同模型、不同任务的词元并不等值**。计量不等值，则定价无公允基准、补贴无核定依据、统计无可加口径、出海无互认凭证。

### 1.2 核心命题（全书理论主轴）
> **词元是智能经济的计量单位，但物理词元不是合格的价值单位；只有经效值折算得到的「标准词元」才能承担价值尺度、定价基准、配置信号与增长核算变量四重经济职能。**

### 1.3 五项理论创新
1. **标准词元（Standard Token Equivalent, STE）折算体系**（第 5 章，全书基石）：借鉴能源经济学「标准煤」、航运「标准箱 TEU」、气候核算「二氧化碳当量」的当量化传统，提出以算力强度 $P$、推理质量 $R$、场景效用 $S$ 三维合成的效值折算函数，并给出基准归一、单调性、可加性、传递一致性四条公理，证明折算函数的存在性与（在公理约束下的）唯一性。
2. **词元定价的三层结构理论**（第 7 章）：将词元价格分解为成本底价层（算力＋能源，决定价格地板）、效值溢价层（模型能力，决定质量梯度）、场景租金层（应用价值的可占有份额，决定纵向差异），据此解释「通用词元价格持续下行」与「高效值词元溢价扩大」并存的结构性分化，并编制词元价格指数（TPI）与标准词元价格指数（STPI）。
3. **算力—词元转化效率与配置悖论的分解**（第 9 章）：构造算力到有效标准词元的转化函数，把「智算利用率仅五至七成而算力仍在扩建」的悖论分解为空转损失、批次损失、匹配损失与效值损失四项，证明统一调度平台经「任务—模型最优匹配」可获得的效率改进上界。
4. **城市词元运营中心的组织模式与机制设计**（第 10 章）：以比较制度分析刻画运营商、城投、数据集团、数据交易所、政策制定者五类运营主体的资产禀赋—职能匹配关系，为城投转型给出「存量基础设施资产再打包」的资产逻辑；以平台—企业—政府三方演化博弈求解「五个统一」制度安排的激励相容条件与补贴退出条件。
5. **基于词元流量的智能经济增长核算**（第 12 章）：将标准词元流量作为可观测变量引入智能经济生产函数，把人工智能的增长贡献从索洛残差中显性分离，回应索洛生产率悖论在人工智能时代的再现，并与 Jorgenson 资本服务测度传统对话。

### 1.4 三个科学问题
- **问题一（计量）**：词元的经济价值由什么决定，异质词元如何折算为可比、可加的标准计量单位？→ 第 3、5、6 章
- **问题二（定价）**：标准词元的价格如何形成、如何演化，词元市场呈现何种结构与均衡？→ 第 7、8 章
- **问题三（配置与增长）**：词元如何在算力、模型与场景之间实现有效配置，其对经济增长的贡献如何测度？→ 第 9、10、11、12 章

## 二、核心概念与符号约定（全书统一，各章不得冲突）

### 2.1 核心概念
| 概念 | 记号 | 界定 |
|---|---|---|
| 物理词元 | $T$ | 大模型分词器切分并计费的原始词元计数，不区分模型与任务 |
| 标准词元 | $\tilde{T}$ | 经效值折算后的当量词元，基准模型在基准任务下的 1 枚词元 ≡ 1 STE |
| 效值系数 | $\eta$ | 折算系数，$\tilde{T}=\eta T$，$\eta$ 由 $(P,R,S)$ 合成 |
| 算力强度 | $P$ | 生成单枚词元所耗浮点运算量相对基准的倍数 |
| 推理质量 | $R$ | 单枚词元承载的有效信息量／任务达成度相对基准的倍数 |
| 场景效用 | $S$ | 应用场景的价值系数，反映所替代人类认知劳动的价值密度 |
| 词元价格 | $p$ | 单位物理词元价格 |
| 标准词元价格 | $\tilde{p}$ | 单位标准词元价格，$\tilde{p}=p/\eta$ |
| 转化效率 | $\theta$ | 单位算力（PFLOPS·h）产出的有效标准词元数 |
| 绿色词元 | $\tilde{T}^{g}$ | 附碳足迹凭证且碳强度低于阈值的标准词元 |
| 碳强度 | $\iota$ | 单位标准词元的二氧化碳当量排放（gCO₂e/kSTE） |

### 2.2 符号约定（防止跨章重名）
- 生产函数：$Y$ 产出、$K$ 资本、$L$ 劳动、$D$ 数据、$\tilde{T}$ 标准词元流量；产出弹性依次记 $\alpha_K,\alpha_L,\alpha_D,\alpha_T$（**不得简写为 α、β 以免与匹配函数、博弈参数混淆**）。
- 定价：$c$ 边际成本、$\mu$ 效值溢价率、$\rho$ 场景租金分成率。
- 博弈：策略比例 $x$（平台深度运营）、$y$（企业深度采纳）、$z$（政府强激励）；成本 $c_{P},c_{F},c_{G}$；收益 $R_{P},R_{F}$；补贴 $s$；错配损失 $L$；调整速度 $\kappa$。
- 调度：任务集 $\mathcal{J}$、模型集 $\mathcal{M}$、匹配矩阵 $\mathbf{X}$、排队强度 $\lambda$、服务率 $\nu$。
- 时间下标一律 $t$，主体下标 $i$，模型下标 $m$，任务下标 $j$，区域下标 $r$。

## 六、事实核查带来的三处重要更正（写作时必须遵守）

**更正一：「词元」定名的主体与效力**
不得写「2026年3月国家数据局正式将Token定名为词元」。核实结论：
- 定名的法定主体是**全国科学技术名词审定委员会**，2026年3月25日发布《关于发布试用人工智能领域名词 token 中文名「词元」的公告》，用语是「**优先推荐**」并「**面向全社会发布试用**」，且明确将在常态化审定中「结合社会推广应用情况**最终确认**」——**不是「正式定名」，不是国家标准**。
- 同月，国家发展改革委党组成员、国家数据局局长**刘烈宏**在**中国发展高层论坛2026年年会**上发表《深化数据赋能人工智能发展，加快培育智能经济新形态》演讲，使用并推介「词元」，提出词元具有「可计量、可定价、可交易」特征，是「智能时代的价值锚点」。
- 两套定义口径不可混用：名词委口径为「具有一定语义的基本符号单元／模型处理和交换信息的最小单位」（术语学口径）；国家数据局口径为「可计量、可定价、可交易的最小信息单元」（经济计量口径）。**本书讨论价值计量时引后者，讨论术语规范时引前者。**

**更正二：日均词元调用量的官方序列**
官方仅有四个锚点：2024年初 1000亿枚／日 → 2025年6月底突破 30万亿 → 2025年底 100万亿 → 2026年3月突破 140万亿（较2024年初增长约1400倍）。
- **「2026年7月180万亿」查无权威出处，全书禁止使用**；2026年7月仅有国家发展改革委在世界人工智能大会上「数百万亿」的定性表述。
- 其余时点为插值，正文与图注必须注明「官方未单独发布，系校准复算插值」。

**更正三：所谓「信通院 P×R×S 三维效值阵」不存在**
多轮检索零命中，「效值」「效值阵」「P×R×S」在信通院及任何机构发布中均无出处。因此：
- 本书的 $(P,R,S)$ 三维效值折算体系是**作者自主构建的理论框架**，不得称其源自或对应信通院，也不得使用「效值阵」这一并不存在的术语指称他人成果。
- 与本书 STE 折算体系构成文献对话的**真实**既有工作有四套，各自主体、维度与用途不同，**引用时必须逐一注明主体，严禁合并、平均或交叉引用维度名称**：
  1. **中国信息通信研究院**《人工智能 Token 服务质量能力要求》→「可信 AI-Token 服务质量评估」，**六维**：模型服务能力、Token服务性能、Token服务可信、Token服务运维、Token服务用户体验、Token计量计费；
  2. **中国信息通信研究院**「高质量 Token 服务标准体系」（2026年6月16日发布），**四维**：服务质量、运营能力、生产能力、安全能力；云大所所长魏凯提出「不能只看单价，行业亟须一套衡量『高质量 Token』的标尺」；
  3. **中国工业互联网研究院**《Token 驱动智能经济研究报告（2026年）》，**五维价值度量**：生产成本、生产效率、准确性、生态价值、安全（**切勿记在信通院名下**）；
  4. **清华大学翟季冬团队联合清程极智**「开源模型 Token 服务性能榜」（2026年5月），**三项实测指标**：首Token时延 TTFT P90、输出吞吐 TPS、缓存命中率。
- **本书相对上述工作的理论增量**（第5章须明确论证）：既有四套体系均为**多维评价**，产出的是并列的维度得分或达标基线（如信通院「词元服务能力攀登计划」首批基线 TPS≥55 Token/s、TTFT≤0.9s、调用成功率99.9%），**无法把异质词元合成为可加总、可计价、可入账的单一当量**；本书的贡献是从「多维评价」推进到「当量折算」——给出公理化的合成函数，使不同模型、不同任务的词元获得可比、可加的共同尺度，从而具备进入价格指数、补贴核定与增长核算的资格。
