# 《数量经济技术经济研究》风格学术论文（两篇）

本目录包含两篇按照《数量经济技术经济研究》期刊风格、逻辑与时态撰写的中文经济学
实证论文，以蔡宇涵、郑新业《高等教育扩招政策与数字技能提升——基于“投资于人”的
视角》为范本，学习其结构（引言—制度背景与理论分析—研究设计—实证结果—机制检验—
异质性分析—结论与政策建议）、因果识别取向、假说驱动的写作逻辑与语言风格。

## 论文清单

1. **论文一：数字基础设施建设与家庭创业——来自“宽带中国”战略的准自然实验**
   - 识别策略：多期双重差分（Staggered DID）+ 事件研究法
   - 数据情境：中国家庭追踪调查（CFPS）风格个体面板 + “宽带中国”示范城市分批建设
   - 机制：信息获取、融资可得、社会网络
   - 异质性：城乡、收入、教育、区域

2. **论文二：工业机器人应用与劳动收入份额——来自中国制造业上市公司的经验证据**
   - 识别策略：双向固定效应 + 巴蒂克（Bartik）工具变量（国外同行业渗透度）
   - 数据情境：制造业上市公司面板 + IFR 行业机器人渗透度
   - 机制：资本深化、生产率、技能结构、成本加成
   - 异质性：要素密集度、所有制、技能结构、企业规模、地区

## 格式说明（满足投稿要求）

- 所有公式均为 Word 原生公式对象（OMML，可用 Word 公式编辑器打开编辑），公式编号右对齐。
- 表格为三线表，**表题在表格上方**；插图**图题在图片下方**。
- 全文使用中文标点。
- 参考文献均为真实文献（经互联网检索核验，含作者、年份、期刊、期号、页码），
  格式符合期刊要求；文内引用与文末参考文献一一对应。

## 数据与结果说明

论文所用微观数据来源于符合上述情境设定的**模拟仿真**（数据生成过程内置真实的处理
效应与机制结构，用于展示完整的实证框架与图表），并非真实调查/公司数据；实证数值、
图表由 `生成脚本/` 中的程序可复现地生成。参考文献均为真实、可检索的公开文献。

## 复现方式

```bash
pip install numpy pandas statsmodels matplotlib scipy python-docx lxml
# 依赖 pandoc 与中文字体（文泉驿正黑）；如需渲染 PDF 另需 libreoffice-writer
cd 生成脚本
python3 sim1.py && python3 sim2.py          # 模拟数据、回归、生成图表(json)
python3 mkref.py                            # 生成期刊风格 reference.docx
python3 render.py 1 && python3 render.py 2  # 注入数值、参考文献、英文摘要
python3 build.py paper1_final.md 论文一.docx # markdown→docx（公式OMML、编号右对齐、三线表）
python3 build.py paper2_final.md 论文二.docx
```
