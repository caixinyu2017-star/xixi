**书名**：《“双碳”目标下中国绿色低碳标准体系研究：动态演化、体系构建与适配性评估》 作者：蔡鑫宇
你的任务：撰写指定章节的 `content_chNN.py`，定义 `def blocks():` 返回 block 字典列表。

## 必读文件（用 Read 工具先读，全部在 green-standards-book/ 目录）

- `content_helpers.py`：可用辅助（c, cc, R, F, pct 等）。

## 硬性要求
1. **字数**：本章正文中文字数（含标点）不少于分配目标（见任务提示；一般 ≥13000 字）。宁多勿少。段落充实、有数据、有分析、有文献对话，坚决避免空话套话与重复注水。
2. **文风**：中文经济学专著风格（《经济研究》《管理世界》《中国工业经济》水准）；论证严密、术语准确；观点—证据—文献三位一体。全部使用中文全角标点（，。；：“”（））；数字与英文字母用半角。
3. **引用**：文中引用一律用 `c('key')`→（作者，年）或 `cc('k1','k2')`→（作者1，年；作者2，年）；句法嵌入用 `c('key', paren=False)`→作者，年。**只能使用 refkeys.txt 中的 key**；严禁杜撰。本章自然引用 ≥14 个不同文献 key（第3、4、9 章 ≥18 个）。
4. **数字纪律**：宏观事实数字取自 `data/facts.md`；模型数字经 `R[...]`（results.json）用 f-string 引用格式化（如 `f"{R['ssa']['A'][0][1]:.3f}"`），**不得手写编造**。表格中的估计值同样从 R 取。
5. **公式**：显示公式用块 `{'eq': r'<LaTeX>', 'num': '5-1'}`（编号=章-序，从 1 连续编）；行内公式用 `$...$`（在 p 文本内）。LaTeX 必须 pandoc 可解析（标准 amsmath 子集；**不要用 \begin{aligned}、\text{中文}**——中文说明放正文；下标用英文缩写）。数理推导要完整：模型设定→求解/估计→性质/命题→经济含义，公式间用文字衔接（“将式(5-1)代入式(5-2)可得”）。推导段落用 `{'lead': '其中，…'}` 说明符号。
6. **图**：用块 `{'fig': 'figs/figN_M.png', 'caption': '图N.M  中文图名', 'width_cm': 13.5}`，只能用 figures_manifest.md 分配给本章的图，在文中相应位置插入并且**正文必须有一段以上明确解读该图**（“由图N.M可见，…”）。
7. **表**：用块 `{'table': {'caption': '表N.M  中文表名', 'header': [...], 'rows': [[...]], 'note': '注：…。数据来源：…。', 'col_align': [...]}}`。表名格式“表N.M  名称”；回归/估计表数值从 R 取并格式化；每张表正文必须有解读。本章表格数量见 DESIGN.md（一般 2—3 张）。
8. **标题层级**：`{'h1': '第N章  标题'}`（每章唯一，块列表第一个）、`{'h2': 'N.1  …'}`、`{'h3': 'N.1.1  …'}`、`{'h4': '…'}`。每章末设“N.x 本章小结”一节（≥600 字）。
9. **段落**：`{'p': '…'}`；无缩进说明段用 `{'lead': '…'}`；要点列举可用 `{'items': [...]}`（少用，优先成段论述）。
10. 文件顶部 `# -*- coding: utf-8 -*-` 与 `from content_helpers import c, cc, R, F, pct`，除 import 与 `def blocks():` 外不得有执行代码。

## 排版与引用铁律（2026-07 作者审阅增补，一切后续修改必须遵守）
1. **先文后图/表**：正文段落必须先出现“如图N.M所示/见表N.M”等提及，图/表块紧随该段**之后**；严禁图表出现在首次提及之前（装配器 `enforce_fig_after_mention` 会兜底重排，但源文件必须按此顺序书写）。
2. **编号按出现顺序**：图N.1、图N.2……严格按其在正文中的出现次序编号，表同理；改动章节结构后必须复核编号次序。
3. **合引按年份升序**：（A，2023；B，2025），`cc()` 已自动按年份排序，禁止手工拼接多篇引用串。
4. **图注**：轴含义、口径、数据来源等说明一律用 fig 块的 `'note'` 字段（渲染于图题下方、小五号宋体、无缩进、两端对齐），**不得放在图片内部**。
5. **机制图学术风格**：连接线一律直线/正交折线（系统动力学因果回路图按学科惯例可用弧线），无图标、无装饰、元素不遮挡不重叠；graphviz `render()` 已默认 `splines=ortho`。

## 版式与文字体例（2026-08 用户复核后追加，各书一体适用；违反即返工）

11. **字体**：正文中文字体宋体、西文字体 Times New Roman，全书统一。
    实现要点在 `docxbuilder.py::_set_run_font`：`w:eastAsia` 给中文字面，
    `w:ascii`／`w:hAnsi` 一律给 Times New Roman，并且**必须设 `w:hint="eastAsia"`**——
    引号“”‘’、破折号——、省略号……在 Unicode 里属「东亚宽度＝歧义」类，
    没有 hint 时 Word 会把它们判给西文字体，排出来是半角直引号，与中文不搭。
    标题用黑体，其西文同样走 Times New Roman。

12. **表格版式**：表内所有单元格的段落**段前 0 磅、段后 0 磅、单倍行距、水平居中、
    垂直居中、首行缩进 0、snapToGrid 关闭**。`col_align`／`first_col_left` 是历史兼容
    参数，不再改变对齐方式。写表时把单元格文字写短，避免居中后折行参差。

13. **引号体例**：全书**不得出现直角引号「」『』**，一律用中文引号 “ ”／‘ ’，外双内单。
    **引号宁缺勿滥**——只在下列情形使用：直接引语／受访者原话；政策专有提法与战略口号
    （“东数西算”“十五五”“人工智能＋”“五个统一”）；反语与非字面义；本书自造概念的**首次**
    出现。核心术语、已定义过的自造术语、普通名词的强调、数量表达，一律不加引号。
    标准名／榜单名／文件名用《》，不用引号。判据：删掉引号后含义不变且不会误读，就删。

14. **术语规范**：同一概念全书只用一个学术界通行词形，不得为求文采同义换用。
    经济学术语尤须核准（网络外部性／需求价格弹性／双边市场／多边平台／复制者动态／
    规模经济／全要素生产率／交易费用／演化稳定策略／经济租金……）。
    「计量」在本书多指 measurement；凡指 econometrics 必须写全「计量经济」。
    首次出现给中文全称＋（英文全称, 缩写），其后只用简称。
    完整清单见 `data/SPEC_TEXT_REVISE.md`。

15. **图内字号**：图件按 13.5—15 cm 版心宽度印刷，**图内最小字符高度不得低于图高的
    1/28**（折算印刷字号约 ≥7.5 pt），框内留白要收紧，严禁「大框小字」。
    机制／框架类概念图（D 型）用 `gpt-image-2` 生成，规范见 `data/SPEC_FIG_REDRAW.md`；
    带真实数据的统计图（A 型）用 matplotlib 绘制并绑定 results.json。
    matplotlib 画 D 型图时须注意：印刷字号＝源字号 × 版心宽度 ÷ 画布宽度，
    画布开得越宽、印出来的字越小。
