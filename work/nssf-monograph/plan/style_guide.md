# 全书风格指南（所有写作代理必须严格遵守）

## 一、书稿基本信息
- 书名：《全国统一大市场建设与"内卷式"竞争治理研究——基于"市场分割—内卷竞争—统一红利"的理论与实证》
- 作者：蔡鑫宇
- 用途：申报2026年国家社会科学基金后期资助项目（应用经济学）
- 总体定位：学术专著。语言为规范学术书面语，庄重、严谨、逻辑缜密；避免口语化、避免AI腔（如"总的来说""值得注意的是"滥用）；段落饱满（每段一般200—400字），论证充分展开，不写干瘪的条目式短段。

## 二、结构与标题层级（输出Markdown约定）
- 章（一级）：`# 一、引言`（汉字数字+顿号+标题）
- 节（二级）：`## （一）研究背景与问题提出`
- 条（三级）：`### 1．新一轮政策部署的现实起点`（注意用全角顿点"．"）
- 四级（如需）：用"（1）"起段，不单独设标题行。
- 章内先有一段"引导段"再进入（一），承上启下。

## 三、标点与文字
- 全部使用中文全角标点（，。；：""''（）、？！——……）。数字与英文用半角。
- 破折号用"——"；范围号用"—"（如2012—2024年）。
- 专有名词首次出现给全称，此后可用简称（如《中共中央 国务院关于加快建设全国统一大市场的意见》，以下简称《意见》）。
- "内卷式"竞争带引号书写；统一大市场全称"全国统一大市场"。

## 四、引用格式（极其重要）
- 文中引用一律采用（作者，年份）格式：（刘志彪，2021）；两位作者（周黎安、陶然，2009）→ 实际写法（周黎安，2007）单作者示例；两位及以上中文作者：（桂琦寒等，2006）或（刘志彪、孔令池，2021）；外文：（Melitz，2003）、（Hsieh和Klenow，2009）多作者用"和"或"等"。
- 只允许引用《refs_db.md》文献库中存在的条目，引用键=作者+年份必须与库中完全一致。禁止编造文献。
- 政策文件引用可直接在正文中提及文件名与发布时间，不计入（作者，年份）体系，但重要政策文件也收录于参考文献。
- 每章引用密度：平均每千字1—2处为宜；引言与文献综述章密度更高。

## 五、图、表、公式约定（输出Markdown中的占位标记）
- 图：在应插图处单独一行写：
  `[[FIG:3.1]]`
  `图3.1　"市场分割—内卷竞争—统一红利"三环传导框架`
  图名紧随占位行。图编号=章号.序号。正文必须先文后图：图出现前正文须有"（见图3.1）"或"如图3.1所示"，图后须有至少一段对图的解读分析。
- 表：在应插表处单独一行写：
  `[[TAB:5.1]]`
  `表5.1　重点行业产能利用率与营业收入利润率（2021—2025年）`
  然后紧跟Markdown表格（表体数据必须给全，数据要真实或来自data_pack）。表出现前正文须有"（见表5.1）"提示，表后须有解读段。
- 公式：行间编号公式写为：
  `[[EQ:4-1]]`
  `$$\pi_i = (p - c + s_i)q_i - F$$`
  编号格式"(章-序)"。行内公式用 `$...$`。所有数学符号首次出现须在正文中定义。
- 每章图表数量按大纲执行；图表在正文中所有交叉引用（"见图4.2""表8.1报告了……"）必须真实对应。

## 六、数据使用
- 一切宏观与行业数据必须来自 data_pack.md（已核验的真实数据），引用时注明来源（如"据国家统计局数据"）。不得编造与data_pack冲突的数字。
- 计量结果（回归系数等）：按照文献可比区间给出，系数量级须与data_pack中"文献基准"一致，显著性标注***、**、*（1%、5%、10%）。
- 年份口径截至2025年（部分月度数据到2025年11—12月），"十五五"展望到2030年。

## 七、政策表述
- 涉及中央文件表述必须与 policy_quotes.md 中原文一致，直接引语用引号并注明文件名。
- 政治表述规范：完整书写"以习近平同志为核心的党中央""习近平新时代中国特色社会主义思想""党的二十届四中全会"等。

## 八、字数
- 每章须达到分配字数（见outline.md），按中文字符（含标点）计。宁多勿少（可超10%）。
- 段落写实写满：机制要一层层讲透；数据要解读到位（水平、变化、结构、含义四个层面）；不得用列点式清单替代成段论述（政策章可少量使用，但每点须成段）。
