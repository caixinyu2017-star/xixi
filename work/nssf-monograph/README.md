# 《全国统一大市场建设与“内卷式”竞争治理研究——基于“市场分割—内卷竞争—统一红利”的理论与实证》

2026年国家社会科学基金后期资助项目申报书稿（应用经济学）。

## 选题依据
选题回应四份中央文件共同锁定的重大现实经济问题：
- 2025年12月中央经济工作会议：“国内供强需弱矛盾突出”“制定全国统一大市场建设条例，深入整治‘内卷式’竞争”；
- 习近平《当前经济工作的重点任务》（《求是》2026年第4期）：产能调控、标准引领、价格执法、质量监管、反垄断反不正当竞争的治理工具箱；
- 党的二十届四中全会：“坚决破除阻碍全国统一大市场建设卡点堵点”；
- 《“十五五”规划纲要》第十七章“纵深推进全国统一大市场建设”。

## 主要创新（顶天）
1. 概念创新：提出并界定“内卷式竞争陷阱”与“统一市场红利”；
2. 理论创新：构建“市场分割—内卷竞争—统一红利”三环传导框架，并以三个递进数理模型（补贴竞争博弈、分割市场过度进入、一体化选择与创新效应）形式化，导出可检验命题H1—H5；
3. 方法与实证：构造省域市场分割指数（相对价格法）与“内卷式竞争”强度指数（五维熵权法），面板固定效应+机制检验+工具变量+公平竞争审查强度DID系统验证。

## 落地价值（立地）
面向《全国统一大市场建设条例》制定、“内卷式”竞争综合整治、地方政府招商引资清单管理、“十五五”统一大市场纵深推进，提出“一个目标、两个支柱、五大工程、一项重构”的政策路径。

## 书稿指标
- 正文约20.7万字（不含参考文献；中文字符含标点），共12章+前言+摘要；
- 图29幅（机制图、理论分析图、数据分析图）、表28张（三线表）、编号公式79个（OMML，居中，编号右顶格）；
- 参考文献146条（GB/T 7714顺序编码制，按正文首次引用排序；文中采用（作者，年份）引注），全部经网络核验真实存在，2021年后文献约六成。

## 目录结构
- `output/`：最终书稿（docx，Word打开后目录域自动更新；另附PDF预览）
- `chapters/`：各章Markdown源稿（含图表公式占位标记）
- `figs/`：全部29幅图（PNG，300dpi）
- `plan/`：全书大纲、风格指南、政策原文素材、数据事实包、实证结果包、参考文献库（JSON）
- `build/`：图表生成与Word组装脚本（python-docx + latex2mathml/mathml2omml）
