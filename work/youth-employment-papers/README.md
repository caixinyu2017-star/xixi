# 青年就业主题论文（《统计与决策》风格）

围绕青年就业方向撰写的两篇中文学术论文及其完整实证流水线。

## 两篇论文

**论文1：《数字经济发展赋能青年高质量就业：机制识别与门槛检验》**

- 样本：2012—2023 年中国 278 个地级及以上城市面板（3336 个观测）
- 方法：熵值法测度 → 双向固定效应 → 稳健性检验 → 工具变量法 → 中介效应 → Hansen 面板门槛模型 → 异质性分析
- 核心发现：数字经济显著提升青年高质量就业水平（系数 0.2631，t=10.21）；通过创业活跃度、产业结构升级、人力资本积累三条渠道传导（中介占比 11.55%、9.89%、14.70%）；存在基于人力资本的双重门槛（门槛值 −0.2917 与 0.7685），跨越后效应由不显著（−0.0050）升至 0.1686 再至 0.3209

**论文2：《人工智能应用对青年就业的替代效应与创造效应：非线性特征与结构分化》**

- 样本：2012—2023 年中国 30 个省份面板（360 个观测）
- 方法：机器人渗透度测度 → 二次项设定识别 U 型 → 就业结构分解 → 稳健性检验 → Bartik 类工具变量与控制函数法 → 机制检验 → 调节效应 → 异质性与分位数回归
- 核心发现：人工智能应用与青年就业规模呈 U 型关系（一次项 −0.0822、二次项 0.0674），拐点约 9.33 台/万人，约 67.8% 观测值仍位于拐点左侧；就业结构呈极化特征（高技能 +1.4237、低技能 −1.7068）；三条渠道的间接效应分别为 −0.0287（替代）、+0.0280（创造）、+0.0158（匹配）；教育与培训显著正向调节

## 目录结构

- `src/paper1.md`、`src/paper2.md`——论文源稿（pandoc markdown，`[@key]` 为引文占位符，`::: {custom-style=...}` 为 Word 样式映射块，公式为 LaTeX 数学，转换后成为 Word 原生公式对象 OMML）
- `src/p1_sim.py`、`src/p2_sim.py`——蒙特卡洛仿真数据生成与全部计量估计脚本
- `src/make_figs2.py`——四幅插图的绘制脚本
- `src/build2.py`——引文编号与参考文献著录生成
- `src/finalize.py`——docx 的期刊化排版后处理
- `results/`——两篇论文的全部估计结果（JSON）与作图数据（CSV）
- `figs/`——四幅插图
- `out/`——两篇最终 Word 文稿
- `refs_verification.md`——参考文献的逐条联网核验记录
- `review_findings.txt`——六个独立审查代理（数值一致性／期刊风格／语言规范 × 两篇）的完整审查意见，共 126 项

## 数据与结果说明

两篇论文的数据均为**蒙特卡洛仿真数据**，指标口径、变量构造与样本结构参照《中国城市统计年鉴》《中国劳动统计年鉴》、北京大学数字普惠金融指数与国际机器人联合会数据的真实统计口径设定。**全部回归结果均由脚本实际估计得到**（linearmodels 的 PanelOLS 与 IV2SLS、statsmodels 的分位数回归），并非人工编写：论文表格中的每一个系数、t 值、样本量、R²、门槛值与自助法 P 值都可由 `src/*_sim.py` 复现，结果留存于 `results/*.json`。

## 质量保障

定稿前经六个独立审查代理逐项核查（每篇分数值一致性、期刊风格、语言规范三个维度），共提出 126 项意见，全部 high 级与绝大部分 medium 级问题已修订，包括：论文 1 异质性表 R² 错位、Sargan 统计量数量级错误、图 1 趋势描述与数据矛盾、基准样本缩尾说明与稳健性检验自相矛盾；论文 2 替代渠道的符号逻辑与理论假设相悖（已回到数据生成层面修正并重新估计）、失业率"倒 U 型"拐点落在样本区间之外、工具变量统计量口径标注等。修订后两篇论文正文中的全部数字（分别为 196 个与 238 个）均已与估计结果文件逐一比对一致。

## 参考文献

两篇论文分别引用 17 条与 20 条文献，全部经联网逐条核验为真实存在（核验依据与来源见 `refs_verification.md`）。核验未能确证的候选文献一律未予采用。

## 构建

```bash
python3 src/p1_sim.py && python3 src/p2_sim.py     # 生成数据并估计（含自助法，耗时较长）
python3 src/make_figs2.py                          # 绘制插图
python3 src/build2.py src/paper1.md paper1_built.md
pandoc paper1_built.md -o out/论文1.docx
python3 src/finalize.py out/论文1.docx
```
