::: {custom-style="AbstractCN"}
**摘 要：**人工智能的加速渗透正在重塑青年劳动力市场的岗位供给与技能需求。文章基于2012—2023年中国30个省份的面板数据，以工业机器人渗透度衡量人工智能应用水平，实证检验其对青年就业的影响效应与作用机制。研究发现：人工智能应用与青年就业规模之间呈显著的U型关系，即在渗透度较低阶段替代效应占优、青年就业规模随之收缩，跨越拐点后创造效应转为主导、青年就业规模转而扩张，样本中约七成观测值仍位于拐点左侧。就业结构检验结果表明，人工智能应用显著提高青年高技能就业占比、降低低技能就业占比，呈现明显的就业极化特征。机制检验结果表明，人工智能应用通过替代常规任务岗位抑制青年就业，同时通过创造新兴数字职业、改善人岗技能匹配促进青年就业，净效应取决于三条渠道的相对强弱。调节效应检验结果表明，教育发展水平与职业技能培训均能显著缓解替代效应、放大创造效应。据此，加快青年技能结构与智能化岗位需求的适配，是把握人工智能就业红利的关键。

# 0 引言

以工业机器人、机器学习与大模型为代表的人工智能技术正在加速向生产与服务领域渗透。国际机器人联合会的数据显示，我国已连续多年位居全球工业机器人装机量首位，2023年制造业机器人密度达到每万名工人470台，超过德国与日本。技术进步在提升生产效率的同时，也在深刻改变劳动力市场的岗位结构与技能需求[@cai2019]。对于初次进入劳动力市场的青年群体而言，这一冲击尤为敏感：一方面，青年缺乏工作经验积累，从事的岗位往往具有较高的常规任务密度，更易被自动化技术替代；另一方面，青年具有较强的学习能力与数字素养，更有可能进入人工智能所创造的新兴职业。在我国青年就业总量压力与结构性矛盾并存的背景下，厘清人工智能应用究竟是“抢走饭碗”还是“创造机会”，以及在何种条件下两种效应此消彼长，对于制定前瞻性的青年就业政策具有重要的现实意义。

与本文相关的文献主要涉及以下三个方面：其一，人工智能与就业的关系研究。国外研究以任务模型为基础指出，技术进步替代常规任务、互补非常规任务，进而引致就业极化[@autor2003;@autor2013;@goos2014]；自动化与新任务创造之间存在动态竞赛，二者的相对速度决定了就业与劳动收入份额的走向[@acemoglu2018]；对德国劳动力市场的研究则发现，机器人虽减少了制造业岗位，但服务业岗位的增长基本抵消了这一损失[@dauth2021]。国内研究方面，学者们发现机器人应用显著影响了中国劳动力市场的岗位结构与工资水平[@wang2020]，工业机器人的使用提高了非常规能力的溢价[@yu2021]，人工智能对就业存在替代与创造的双重作用[@he2020]，并会诱致劳动收入不平等[@wanglinhui2020]、推动产业结构转型与劳动收入份额变动[@guo2019]。近期研究进一步基于大语言模型测算了我国职业的人工智能技术暴露度，发现暴露度上升会显著抑制相关岗位的劳动力需求[@zhang2025]。其二，人工智能对生产率与工作方式的影响研究。已有研究发现人工智能能够通过调整劳动力技能结构提升企业生产效率[@yao2024]，生成式人工智能对客服等职业的效率提升作用显著且以新手获益最大[@bryn2025]，多数知识工作任务已不同程度地暴露于大模型能力范围之内[@eloundou2024]。其三，青年就业的专门研究。学者们系统梳理了我国青年就业研究的核心议题[@xu2024]，刻画了青年就业“量减质升”的阶段特征[@guo2022]，并发现教育错配显著抑制青年就业质量[@ding2024]；国外研究则表明，在劳动力市场疲软时期进入职场会对青年产生长期的收入与职业发展损失[@kahn2010]。

梳理现有文献可知，已有研究对人工智能的就业效应进行了富有成效的探索，但仍有可拓展之处：一是多数研究考察全体劳动者或制造业工人的就业结果，专门聚焦青年群体的实证证据相对匮乏；二是替代效应与创造效应多被分别讨论，鲜有研究在统一框架下刻画二者相对强弱随技术渗透深化而发生的动态转换，从而难以回答“净效应何时由负转正”这一关键问题；三是对缓解替代冲击的条件性因素缺乏系统检验。鉴于此，本文以2012—2023年30个省份的面板数据为样本，通过引入人工智能应用水平的二次项刻画替代与创造效应的动态转换，并从常规任务替代、新兴岗位创造与人岗技能匹配三条渠道识别作用机制，进而检验教育发展水平与职业技能培训的调节作用，以期为青年就业政策提供经验依据。

# 1 理论分析与研究假设

## 1.1 替代效应、创造效应与非线性净效应

依据任务模型的分析框架，技术进步对就业的影响取决于其对不同任务的替代与互补关系[@autor2003]。人工智能应用对青年就业同时存在两种方向相反的作用力。就替代效应而言，人工智能擅长处理程式化、可编码的常规任务，而青年因经验积累不足，初入职场时承担的多为流程性、辅助性岗位，常规任务密度较高，因而首当其冲地面临岗位替代风险[@wang2020]。就创造效应而言，人工智能的应用催生了算法训练、数据标注、智能运维、人机协作管理等新兴职业，同时通过提高生产率、降低产品价格扩大市场需求，进而在关联部门引致新的用工需求[@acemoglu2018;@dauth2021]。

两种效应的相对强弱随技术渗透程度的加深而发生系统性转换。在人工智能应用的起步阶段，技术投入主要用于替代既有的重复性劳动环节，企业以“机器换人”降低成本的动机占主导，而配套的数字基础设施、组织流程与商业模式尚未成熟，新兴岗位的孵化能力有限，因此替代效应占优，青年就业规模趋于收缩。随着渗透度持续提高，人工智能由单点替代转向系统性重构，产业链上下游衍生出大量新职业与新业态，通用目的技术所要求的互补性投资逐步到位[@bresnahan1995]，加之技术扩散降低了应用门槛、催生中小企业的新增用工需求，创造效应逐步超越替代效应，青年就业规模转而扩张。基于此，本文提出：

假设1：人工智能应用与青年就业规模之间呈U型关系，即随渗透度提高先抑制后促进。

## 1.2 作用机制

第一，常规任务替代渠道。人工智能对常规任务岗位的替代直接压缩了青年的传统就业空间。制造业流水线操作、基础数据录入、标准化客服等常规任务密集型岗位历来是青年尤其是低学历青年进入劳动力市场的主要通道，这类岗位的萎缩会直接减少青年就业机会[@goos2014;@yu2021]。

第二，新兴岗位创造渠道。人工智能的产业化应用衍生出算法工程、数据服务、智能装备运维、数字内容生产等新兴职业，这类岗位普遍具有知识密集、技能更新快的特征，对熟悉数字工具、学习能力较强的青年具有天然的吸纳优势[@zhang2025]。

第三，人岗技能匹配渠道。人工智能不仅改变岗位供给，也重塑了匹配过程：智能招聘与人岗匹配算法提高了简历筛选与岗位推荐的精准度，降低了青年因信息不对称造成的摩擦性失业；同时人工智能的应用倒逼企业明确岗位技能画像，有助于青年在求职前有针对性地补齐技能短板，从而提高匹配质量并降低离职率[@ding2024]。基于此，本文提出：

假设2a：人工智能应用通过替代常规任务岗位抑制青年就业。

假设2b：人工智能应用通过创造新兴数字职业促进青年就业。

假设2c：人工智能应用通过改善人岗技能匹配促进青年就业。

## 1.3 调节效应

人工智能对青年就业的净效应并非外生给定，而是取决于青年劳动力的技能结构能否与智能化岗位需求相适配。教育发展水平较高的地区，青年劳动力的认知能力与非常规任务处理能力更强，更易向人工智能难以替代的岗位转移，同时更有能力承接新兴数字职业的技能要求，因而替代冲击更易被吸收、创造红利更易被捕获[@yao2024]。职业技能培训则提供了教育体系之外的技能更新通道，通过短周期、高针对性的培训帮助青年劳动者完成从被替代岗位向新兴岗位的转换，缩短技术冲击下的职业转换期。基于此，本文提出：

假设3：教育发展水平与职业技能培训能够正向调节人工智能应用对青年就业的影响。

# 2 研究设计

## 2.1 模型构建

为检验人工智能应用对青年就业的非线性影响，构建如下基准回归模型：

$$\operatorname{lnyemp}_{it} = \alpha_{0} + \alpha_{1}\operatorname{ai}_{it} + \alpha_{2}\operatorname{ai}_{it}^{2} + \alpha_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（1）$$

其中，$\operatorname{lnyemp}_{it}$为省份*i*在年份*t*的青年就业规模，$\operatorname{ai}_{it}$为人工智能应用水平，$\operatorname{ai}_{it}^{2}$为其二次项，$\operatorname{Controls}_{it}$为控制变量，$\mu_{i}$、$\delta_{t}$、$\varepsilon_{it}$分别为省份固定效应、年份固定效应与随机扰动项。若$\alpha_{1} < 0$且$\alpha_{2} > 0$，则二者呈U型关系，拐点为：

$$\operatorname{ai}^{*} = - \frac{\alpha_{1}}{2\alpha_{2}}\quad\quad（2）$$

为识别作用机制，构建如下中介效应模型：

$$M_{it} = \beta_{0} + \beta_{1}\operatorname{ai}_{it} + \beta_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（3）$$

$$\operatorname{lnyemp}_{it} = \gamma_{0} + \gamma_{1}\operatorname{ai}_{it} + \gamma_{2}M_{it} + \gamma_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（4）$$

其中，$M_{it}$为中介变量，包括常规任务岗位占比（*routine*）、新兴数字职业占比（*newjob*）与人岗技能匹配度（*match*）。

为检验调节效应，构建如下模型：

$$\operatorname{lnyemp}_{it} = \varphi_{0} + \varphi_{1}\operatorname{ai}_{it} + \varphi_{2}\operatorname{ai}_{it}^{2} + \varphi_{3}Z_{it} + \varphi_{4}\operatorname{ai}_{it} \times Z_{it} + \varphi_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（5）$$

其中，$Z_{it}$为调节变量，包括教育发展水平（*edu*）与职业技能培训（*train*），二者均作中心化处理。

## 2.2 变量选取

2.2.1 被解释变量

青年就业规模（*lnyemp*）。以各省份16—34岁城镇就业人员数量的自然对数衡量。稳健性检验中另采用青年就业人数占城镇总就业人数的比重（*yshare*）作为替代测度。

2.2.2 核心解释变量

人工智能应用水平（*ai*）。借鉴机器人渗透度的构造思路[@acemoglu2018;@wang2020]，以国际机器人联合会公布的分行业工业机器人存量，按各省份基期分行业就业份额加权后除以就业人数得到省级机器人渗透度（台/万人），并取自然对数后作标准化处理。

2.2.3 中介变量

常规任务岗位占比（*routine*），参照任务模型的职业分类，以从事常规性、程式化任务的就业人员占比衡量；新兴数字职业占比（*newjob*），以信息传输、软件和信息技术服务业及数字相关新职业从业人员占比衡量；人岗技能匹配度（*match*），以劳动力市场求人倍率与学历—岗位匹配度合成的指标衡量，取值介于0与1之间。

2.2.4 调节变量与控制变量

调节变量为教育发展水平（*edu*），以高等教育毛入学率衡量；职业技能培训（*train*），以参加政府补贴性职业技能培训人次占城镇就业人员的比重衡量。控制变量包括：经济发展水平（*lnpgdp*），以人均地区生产总值的自然对数衡量；产业结构（*indus*），以第三产业与第二产业增加值之比衡量；对外开放水平（*open*），以进出口总额与地区生产总值之比衡量；城镇化水平（*urban*），以城镇常住人口占比衡量；财政支出规模（*fis*），以一般公共预算支出与地区生产总值之比衡量；工资水平（*wage*），以城镇单位就业人员平均工资的自然对数衡量。

## 3.2 就业结构效应

## 3.4 内生性检验

人工智能应用与青年就业之间可能存在双向因果：青年劳动力供给相对短缺的地区，企业采用机器人替代人工的动机更强。为此，本文构造两个工具变量：一是参照Bartik类工具变量的思路，以美国同期机器人渗透度与本省基期制造业就业份额的交乘项（$iv_{1}$）作为外生的技术冲击；二是以基期装备制造业产值占比与全国机器人装机量的交乘项（$iv_{2}$）度量技术采纳的产业基础。两个工具变量均通过影响技术采纳成本与产业适配性作用于本省机器人渗透度，而不直接影响当期青年就业。

# 4 结论与建议

本文基于2012—2023年中国30个省份的面板数据，实证检验了人工智能应用对青年就业的影响效应与作用机制，主要结论如下：第一，人工智能应用与青年就业规模之间呈显著的U型关系，拐点位于机器人渗透度约9.82台/万人处，样本中约69.7%的观测值仍位于拐点左侧，表明现阶段多数省份仍处于替代效应占优的区间，该结论经稳健性与内生性检验后依然成立。第二，就业结构检验表明，人工智能应用显著提高青年高技能就业占比、降低低技能就业占比，同时压缩常规任务岗位、扩张新兴数字职业，呈现明显的就业极化特征；青年失业率则呈与就业规模相镜像的倒U型变化。第三，机制检验表明，人工智能应用通过替代常规任务岗位抑制青年就业，通过创造新兴数字职业与改善人岗技能匹配促进青年就业。第四，教育发展水平与职业技能培训均能显著正向调节人工智能的就业效应；异质性分析表明替代冲击在西部地区与非制造业密集地区更为突出，分位数回归表明青年就业规模较大的省份跨越拐点所需的技术渗透度更高。

基于上述结论，本文提出如下建议：第一，前瞻应对替代效应集中释放期。鉴于多数省份仍处于U型曲线左半支，应将常规任务密集型行业的青年从业人员作为重点帮扶对象，建立岗位替代风险的监测预警机制，对受冲击较大的行业与地区提前部署转岗培训与就业援助，避免替代冲击集中释放引发结构性失业。第二，加快培育人工智能衍生的新职业。应完善新职业发布与职业标准制定机制，推动算法工程、数据服务、智能运维、数字内容等新兴职业的规范化与体系化发展，通过产业配套政策引导人工智能应用由单点替代转向系统重构，缩短从替代主导阶段迈向创造主导阶段的过渡期。第三，强化教育与培训的缓冲功能。一方面推动高等教育与职业教育的专业设置对接智能化岗位需求，将人工智能通识教育与数字技能培养纳入人才培养方案；另一方面扩大政府补贴性职业技能培训的覆盖面与针对性，重点面向被替代风险较高的青年群体开展转岗培训，切实发挥技能培训对替代冲击的缓释作用。第四，实施区域差异化政策。西部地区与非制造业密集地区应重点防范替代冲击，在推进智能化改造的同时同步布局配套产业与培训体系；东中部地区与制造业密集地区则应着力放大创造效应，依托完善的产业配套加快孵化人工智能关联岗位，为青年提供更具成长性的职业发展空间。
