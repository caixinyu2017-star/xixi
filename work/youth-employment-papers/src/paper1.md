**摘 要：**文章基于2012—2023年中国278个地级及以上城市的面板数据，运用熵值法测度青年高质量就业水平与数字经济发展水平，实证检验数字经济对青年高质量就业的影响效应及作用机制。研究发现：（1）数字经济发展能够显著提升青年高质量就业水平，该结论在经过一系列稳健性与内生性检验后依然成立。（2）作用机制检验结果表明，数字经济可通过激发创业活跃度、推动产业结构升级、促进人力资本积累三条渠道赋能青年高质量就业。（3）门槛效应检验结果表明，数字经济的赋能作用存在基于人力资本水平的双重门槛特征，只有当人力资本跨越第一门槛后赋能效应才由不显著转为显著，并在跨越第二门槛后进一步增强。（4）异质性检验结果表明，数字经济的赋能作用在中西部地区、大规模城市以及非中心城市中更为突出。

# 0 引言

青年就业是就业工作的重中之重，关系经济社会发展全局与代际公平。近年来，我国青年劳动力市场面临总量压力与结构性矛盾交织的复杂局面：一方面，高校毕业生规模连年攀升，2024年达1179万人；另一方面，青年群体就业的稳定性、报酬水平与发展空间仍有较大改善余地，“就业难”与“招工难”并存的摩擦性、结构性矛盾较为突出。党的二十届三中全会明确提出“完善就业公共服务体系，着力解决结构性就业矛盾”，促进青年高质量充分就业已成为兼具理论价值与现实紧迫性的重大议题。与此同时，数字经济作为重组要素资源、重塑经济结构的关键力量，正在深刻改变劳动力市场的岗位供给结构、技能需求结构与人岗匹配方式[@jiang2022]。在此背景下，系统考察数字经济发展能否赋能青年高质量就业、通过何种渠道赋能以及在何种条件下赋能，对于优化就业政策设计、释放数字经济的就业红利具有重要意义。

与本文相关的文献主要涉及以下三个方面：其一，数字经济的就业效应研究。田鸽和张勋（2022）[@tian2022]发现数字经济能够通过深化社会分工推动非农就业增长，戚聿东等（2020）[@qi2020]认为数字经济可优化就业结构并提升就业质量，杨伟国和吴邦正（2022）[@yang2022]指出平台经济的兴起重塑了就业形态与结构，李建奇和黄维晨（2024）[@li2024]基于网络招聘大数据发现平台经济具有显著的包容性就业特征。但柏培文和张云（2021）[@bai2021]也提示，数字经济在人口红利下降背景下可能损害中低技能劳动者权益。其二，青年就业的相关研究。徐明等（2024）[@xu2024]系统梳理了我国青年就业研究的核心议题与演进脉络，郭冉等（2022）[@guo2022]基于中国社会状况综合调查发现青年就业呈现“量减质升”的阶段特征，丁述磊等（2024）[@ding2024]揭示教育错配会显著抑制青年就业质量；Kahn（2010）[@kahn2010]则表明，青年在经济下行期进入劳动力市场会承受长期的工资与职业发展损失。其三，数字经济影响就业的机制研究。赵涛等（2020）[@zhao2020]发现数字经济能够显著提升创业活跃度并推动高质量发展，刘翠花（2022）[@liu2022]验证了数字经济对产业结构升级与创业增长的促进作用，韩先锋等（2019）[@han2019]则指出互联网普及是区域创新效率提升的新动能。

梳理现有文献可知，已有研究为理解数字经济的就业效应奠定了基础，但仍存在拓展空间：一是多数研究聚焦于就业总量、就业结构或全体劳动者的就业质量，专门针对青年群体高质量就业的系统性实证考察相对不足；二是对数字经济赋能就业的作用渠道虽有讨论，但缺乏在统一框架下对创业创造、产业升级与人力资本积累三条渠道的并行检验；三是鲜有研究关注数字经济就业效应的非线性特征，即赋能作用是否依赖于本地人力资本条件而呈现门槛式跃迁。鉴于此，本文基于2012—2023年278个地级及以上城市的面板数据，构建青年高质量就业评价指标体系，实证检验数字经济的赋能效应、传导渠道与门槛条件，以期为差异化的青年就业政策提供经验依据。

# 1 理论分析与研究假设

## 1.1 直接影响

数字经济主要通过三条路径直接提升青年高质量就业水平。第一，扩大岗位供给。数字技术的渗透催生了平台运营、数据分析、直播电商、智能运维等新职业新岗位，这类岗位普遍具有知识密集度高、技能更新快、从业者年龄结构年轻的特征，与青年群体的数字素养优势高度契合，从而扩大了适配青年的岗位规模[@yang2022]。第二，降低匹配摩擦。数字招聘平台与劳动力市场信息系统显著缩短了求职者与用人单位之间的信息搜寻半径、降低了匹配成本，使青年能够更快找到与自身专业背景和技能结构相适配的岗位，减少因信息不对称导致的教育错配与技能错配[@ding2024;@li2024]。第三，改善就业条件。数字化管理工具的普及提升了企业人力资源管理的规范化水平，社会保险参保、劳动合同签订等制度性保障更易落实；同时数字经济部门较高的劳动生产率也为青年提供了更具竞争力的薪酬和更通畅的职业发展通道[@qi2020]。基于此，本文提出：

假设1：数字经济发展能够显著提升青年高质量就业水平。

## 1.2 间接影响

创业活跃度是数字经济赋能青年就业的重要渠道。数字技术大幅降低了创业的资金门槛、渠道门槛与市场准入门槛，电子商务、社交电商与数字支付体系使小微创业者能够以较低成本触达全国市场，数字普惠金融的发展亦缓解了青年创业者的融资约束[@zhao2020]。创业活跃度提升不仅直接创造自雇型就业机会，更通过新设企业的用工需求形成“以创业带就业”的乘数效应，而新设企业的用工偏好又通常向青年倾斜。

产业结构升级是另一重要渠道。数字经济通过数据要素与实体经济的深度融合推动传统产业智能化改造与服务业高端化发展，第三产业尤其是生产性服务业、信息服务业的比重上升[@liu2022]。这类行业的岗位技能要求与青年的受教育结构更为匹配，且提供了更规范的用工关系与更清晰的晋升通道，从而在结构层面改善青年就业质量。

人力资本积累构成第三条渠道。数字经济的发展提高了技能溢价，强化了个体与家庭的教育投资激励；在线教育、数字技能培训平台的普及降低了技能习得成本，使青年劳动者能够以更低成本完成技能升级[@chen2022]。人力资本水平的提升直接增强青年的岗位胜任力与议价能力，进而提高其就业稳定性与报酬水平。基于此，本文提出：

假设2：数字经济通过激发创业活跃度提升青年高质量就业水平。

假设3：数字经济通过推动产业结构升级提升青年高质量就业水平。

假设4：数字经济通过促进人力资本积累提升青年高质量就业水平。

## 1.3 非线性影响

数字经济对青年高质量就业的赋能作用可能并非线性，而是取决于本地人力资本的适配程度。依据技能偏向型技术进步理论，数字技术与高技能劳动力形成互补，对常规低技能岗位形成替代[@autor2003]。在人力资本水平较低的城市，数字技术创造的岗位所要求的技能与本地青年劳动力的技能存量之间存在显著缺口，岗位空缺与求职困难并存，数字经济的岗位创造效应难以有效转化为本地青年的就业改善，甚至可能因替代常规岗位而对中低技能青年形成挤压[@bai2021]。当人力资本积累跨越一定门槛后，本地青年具备承接数字化岗位的能力基础，技能与岗位的匹配效率显著改善，赋能效应开始显现。随着人力资本进一步提升并跨越更高门槛，本地形成了规模化的高技能青年人才集聚，不仅能够充分吸纳数字经济创造的高质量岗位，还会通过知识溢出吸引数字企业进一步集聚，赋能效应因而进一步放大。基于此，本文提出：

假设5：数字经济对青年高质量就业的赋能作用存在基于人力资本水平的门槛效应。

# 2 研究设计

## 2.1 模型构建

为检验数字经济发展对青年高质量就业的影响，构建如下基准回归模型：

$$\operatorname{yqe}_{it} = \alpha_{0} + \alpha_{1}\operatorname{dig}_{it} + \alpha_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（1）$$

其中，$\operatorname{yqe}_{it}$为城市*i*在年份*t*的青年高质量就业水平，$\operatorname{dig}_{it}$为数字经济发展水平，$\operatorname{Controls}_{it}$为一系列控制变量，$\mu_{i}$、$\delta_{t}$、$\varepsilon_{it}$分别表示城市固定效应、年份固定效应与随机扰动项。

为检验数字经济影响青年高质量就业的作用渠道，构建如下中介效应模型：

$$M_{it} = \beta_{0} + \beta_{1}\operatorname{dig}_{it} + \beta_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（2）$$

$$\operatorname{yqe}_{it} = \gamma_{0} + \gamma_{1}\operatorname{dig}_{it} + \gamma_{2}M_{it} + \gamma_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（3）$$

其中，$M_{it}$为中介变量，包括创业活跃度（*entre*）、产业结构升级（*upg*）与人力资本水平（*hc*），其余变量含义同式（1）。

为检验数字经济赋能作用的非线性特征，以人力资本水平为门槛变量，构建如下面板门槛模型：

$$\operatorname{yqe}_{it} = \theta_{0} + \theta_{1}\operatorname{dig}_{it} \times I(\operatorname{hc}_{it} \leq \gamma_{1}) + \theta_{2}\operatorname{dig}_{it} \times I(\gamma_{1} < \operatorname{hc}_{it} \leq \gamma_{2}) + \theta_{3}\operatorname{dig}_{it} \times I(\operatorname{hc}_{it} > \gamma_{2}) + \theta_{j}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（4）$$

其中，$\gamma_{1}$、$\gamma_{2}$为待估门槛值，$I( \cdot )$为示性函数，满足括号内条件时取1，否则取0。

## 2.2 变量选取

### 2.2.1 被解释变量

青年高质量就业水平（*yqe*）。参考戚聿东等（2020）[@qi2020]与郭冉等（2022）[@guo2022]关于就业质量测度的研究，本文从就业充分性、就业稳定性、就业报酬、就业保障与就业发展5个维度选取8项具体指标构建青年高质量就业评价指标体系（见表1），并采用熵值法测算综合指数。熵值法的具体步骤为：首先对各项指标作极差标准化处理，正向指标与负向指标分别按下式处理：

$$x_{ij}^{'} = \frac{x_{ij} - \min x_{j}}{\max x_{j} - \min x_{j}},\quad x_{ij}^{'} = \frac{\max x_{j} - x_{ij}}{\max x_{j} - \min x_{j}}\quad\quad（5）$$

其次计算第*j*项指标的熵值$e_{j}$与权重$w_{j}$：

$$e_{j} = - \frac{1}{\ln n}\sum_{i = 1}^{n}p_{ij}\ln p_{ij},\quad w_{j} = \frac{1 - e_{j}}{\sum_{j = 1}^{m}(1 - e_{j})}\quad\quad（6）$$

其中，$p_{ij} = x_{ij}^{'}/\sum_{i = 1}^{n}x_{ij}^{'}$，*n*与*m*分别为样本量与指标个数。最后按$\operatorname{yqe}_{i} = \sum_{j = 1}^{m}w_{j}x_{ij}^{'}$合成综合指数。

### 2.2.3 中介变量

创业活跃度（*entre*），以每万人新登记注册企业数衡量；产业结构升级（*upg*），以第三产业增加值与第二产业增加值之比衡量；人力资本水平（*hc*），以普通高等学校在校学生数占常住人口的比重衡量。

### 2.2.4 控制变量

参考已有研究，本文选取以下控制变量：经济发展水平（*pgdp*），以人均地区生产总值的自然对数衡量；政府干预程度（*gov*），以一般公共预算支出与地区生产总值之比衡量；对外开放水平（*open*），以进出口总额与地区生产总值之比衡量；城镇化水平（*urban*），以城镇常住人口占比衡量；教育投入强度（*edu*），以教育支出占一般公共预算支出的比重衡量；基础设施水平（*infra*），以人均城市道路面积的自然对数衡量。

## 3.3 内生性检验

数字经济与青年高质量就业之间可能存在反向因果与遗漏变量导致的内生性问题：青年高质量就业水平较高的城市往往对数字人才更具吸引力，从而反向推动数字经济发展。为此，本文采用工具变量法予以处理。参照历史工具变量的构造思路，选取1984年各城市每万人固定电话数量与当年全国互联网普及率的交乘项作为第一个工具变量（$iv_{1}$），选取城市地形起伏度与当年全国电信业务总量的交乘项作为第二个工具变量（$iv_{2}$）。历史通信基础与自然地理条件会影响数字基础设施的铺设成本进而影响当期数字经济发展水平，满足相关性要求；同时二者均不会直接作用于当期青年就业质量，满足外生性要求。

表6报告了两阶段最小二乘估计结果。第一阶段结果显示，两个工具变量的系数分别在1%和5%的水平上显著，且第一阶段*F*统计量为111.3635，远大于经验临界值10，不存在弱工具变量问题；Sargan过度识别检验的*P*值为0.8661，无法拒绝“所有工具变量均外生”的原假设。第二阶段结果显示，数字经济发展水平的系数为0.3696，在1%的水平上显著为正，且大于基准回归的估计值，表明在缓解内生性偏误后数字经济的赋能效应依然成立，且基准回归可能因测量误差而低估了真实效应。

# 4 结论与建议

## 4.1 结论

本文基于2012—2023年中国278个地级及以上城市的面板数据，实证检验了数字经济发展对青年高质量就业的影响效应及作用机制，主要结论如下：第一，数字经济发展能够显著提升青年高质量就业水平，该结论在经过缩尾处理、剔除特殊样本、调整样本区间、替换变量测度方式等一系列稳健性检验以及工具变量法的内生性检验后依然成立。第二，作用机制检验结果表明，数字经济可通过激发创业活跃度、推动产业结构升级、促进人力资本积累三条渠道间接赋能青年高质量就业，其中人力资本积累渠道的中介作用最强。第三，数字经济的赋能作用存在基于人力资本水平的双重门槛效应，在跨越第一门槛之前赋能效应并不显著，跨越门槛后赋能系数显著提高并呈阶梯式增强特征。第四，异质性分析结果表明，数字经济的赋能作用在中西部地区、大规模城市以及非中心城市中更为突出。

## 4.2 建议

基于上述结论，本文提出如下建议：第一，加快数字经济与就业服务体系的深度融合。应持续推进数字基础设施向中西部地区与中小城市延伸，支持数字招聘平台建设与公共就业服务数字化转型，扩大数字经济对青年岗位的创造能力与匹配效率，切实降低青年求职的信息搜寻成本与匹配摩擦。第二，畅通三条赋能渠道。一是完善青年创业扶持政策体系，通过创业担保贷款、税费减免、创业孵化基地等举措降低数字创业门槛；二是引导数字技术与实体经济深度融合，加快生产性服务业与信息服务业发展，创造更多适配青年的高质量岗位；三是将数字技能培训纳入公共职业培训体系，扩大在线职业教育资源供给。第三，重视人力资本门槛的约束作用。对于尚未跨越第一门槛的城市，应把提升本地人力资本存量作为承接数字经济就业红利的先决条件，通过加大高等教育与职业教育投入、优化人才引进政策、加强校企协同育人等方式加快人力资本积累，避免因技能与岗位错配而使数字经济红利外溢。第四，实施差异化的区域就业政策。中西部地区与非中心城市应抓住数字经济后发优势，重点补齐数字基础设施与人才培养短板；东部地区与中心城市则应着力推动数字经济由规模扩张向质量提升转变，通过发展高附加值数字产业为青年创造更具成长性的职业发展空间。
