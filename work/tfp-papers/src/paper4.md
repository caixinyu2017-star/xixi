**摘 要：**文章基于2011—2023年中国30个省份的面板数据，采用空间杜宾模型与面板门槛模型，系统考察人口老龄化影响全要素生产率的空间溢出效应与非线性特征。研究发现：（1）全要素生产率与人口老龄化均呈现显著的正向空间自相关，采用空间计量模型具有必要性；LM检验、LR检验与Wald检验一致支持时空双固定效应的空间杜宾模型设定。（2）效应分解结果表明，老龄化率每提高1个百分点，本地全要素生产率下降1.53%，通过空间渠道使邻近地区下降2.66%，总效应为−4.18%，间接效应约为直接效应的1.74倍，说明忽略空间溢出会严重低估老龄化的生产率损失。（3）上述结论在更换三类空间权重矩阵、替换被解释变量、缩尾处理、调整样本区间、动态空间杜宾模型以及以历史人口结构为工具变量的两阶段最小二乘和控制函数法下均保持稳健。（4）以研发强度为门槛变量的检验显示存在双重门槛，当研发强度跨越1.2786与2.2323两个门槛后，老龄化的抑制作用由−0.0265依次减弱至−0.0203和−0.0109。（5）老龄化通过降低劳动参与率抑制生产率，同时通过诱致自动化替代与人力资本深化形成部分对冲；抑制作用在西部地区最强、东部地区最弱。

# 0 引言

我国已进入中度老龄化社会。第七次全国人口普查以来，65岁及以上人口占比持续攀升，2023年已达15.4%，且区域分布高度不均衡。在劳动力总量趋于收缩、人口红利加速衰减的背景下[@bai2021]，全要素生产率能否接续成为经济增长的主要动力源，直接关系到高质量发展的实现路径。厘清人口老龄化对全要素生产率的影响方向、作用强度与边界条件，因而具有重要的理论价值与政策含义。

值得注意的是，人口老龄化的经济后果难以被行政边界所限定。劳动力跨区流动、产业链跨区分工与技术跨区扩散意味着一个地区的年龄结构变化会经由要素市场与产品市场传导至相邻地区；同时，我国省际老龄化水平本身也呈现出明显的空间集聚特征。在这种情形下，忽略空间关联的传统面板模型既无法识别老龄化的溢出效应，也会因残差的空间相关而导致估计失效。此外，已有研究提示老龄化与技术进步之间可能存在非线性关系：Acemoglu和Restrepo（2022）[@acemoglu2022]的诱致性创新理论表明，劳动力短缺会激励企业加快自动化技术的采用与研发，从而部分抵消老龄化的负面冲击，而这种对冲能力显然取决于地区的技术基础。

与本文相关的研究主要涉及三个方面。其一，人口老龄化的宏观经济效应。胡鞍钢等（2012）[@hu2012]基于省际面板数据发现老龄化对经济增长存在显著的负向影响；汪伟和王春超（2025）[@wang2025]系统梳理了人口转变、人口红利与人口老龄化之间的内在逻辑；Maestas等（2023）[@maestas2023]利用美国州际数据识别出60岁及以上人口占比每提高10%会使人均GDP下降5.5%，其中约三分之二源于劳动生产率增速的放缓。其二，老龄化与技术进步的关系。Acemoglu和Restrepo（2022）[@acemoglu2022]发现人口老龄化更快的国家和地区采用机器人等自动化技术更为积极；沈可和李雅凝（2021）[@shen2021]基于系统GMM与动态面板门槛模型发现老龄化与科技创新之间呈驼峰型关系；王永钦和董雯（2020）[@wang2020]、Dauth等（2021）[@dauth2021]则分别从中国与德国的经验出发考察了机器人应用对劳动力市场的影响。其三，空间计量方法在区域生产率研究中的应用。邵帅等（2022）[@shao2022]运用空间杜宾模型考察了经济结构调整与绿色技术进步对碳排放绩效的直接效应与间接效应；沈可和孙慧琳（2024）[@shen2024]基于地级市面板数据识别了老龄化对科技创新的空间效应与门槛特征。

梳理已有文献可知，仍存在三方面拓展空间。第一，多数研究在非空间框架下估计老龄化的生产率效应，既未识别其跨区溢出，也未对模型设定作系统检验，所得系数实为直接效应与部分溢出效应的混合。第二，虽有研究注意到老龄化影响的非线性，但门槛变量多选取城镇化率或经济发展水平，鲜有从诱致性技术创新的理论逻辑出发，直接以研发强度作为刻画地区技术对冲能力的门槛变量。第三，老龄化本身可能因劳动力外流而与生产率冲击互为因果，既有研究对这一内生性问题的处理相对薄弱。

鉴于此，本文基于2011—2023年30个省份的面板数据展开研究，边际贡献在于：第一，在空间杜宾模型框架下运用偏微分法将老龄化的生产率效应分解为直接效应、间接效应与总效应，并借助三类空间权重矩阵检验结论的稳健性，量化了忽略空间溢出所导致的低估程度；第二，从诱致性创新理论出发，以研发强度为门槛变量识别老龄化影响的非线性结构，为"技术进步能否对冲人口红利消退"提供了可度量的判别标准；第三，以1982年人口普查的少儿人口占比与时间趋势的交乘项为工具变量，同时采用两阶段最小二乘与控制函数法处理老龄化的内生性，并在空间模型中直接检验其外生性。

# 1 理论分析与研究假设

## 1.1 人口老龄化的直接效应

人口老龄化主要通过三条路径作用于本地全要素生产率。第一，劳动供给收缩效应。老龄化直接降低劳动年龄人口比重与劳动参与率，使企业面临更强的用工约束与更高的用工成本，部分岗位因难以匹配而闲置，既有生产能力的利用效率随之下降[@hu2012]。第二，创新活力衰减效应。年龄结构老化会削弱劳动力的学习能力、风险偏好与技能更新速度，降低创业活跃度与新技术的采纳意愿，从而抑制技术前沿的外推速度[@shen2021]。第三，资源配置扭曲效应。老龄化推高养老与医疗等刚性支出在财政支出中的比重，挤占了地方政府在基础研究、公共基础设施与产业升级方面的投入，同时储蓄结构与投资结构的改变也会影响资本配置效率。基于此，本文提出：

假设1：人口老龄化会显著抑制本地全要素生产率的提升。

## 1.2 空间溢出效应

人口老龄化的影响会经由三类空间渠道外溢至邻近地区。第一，劳动力流动渠道。相邻地区在劳动力市场上高度联通，一地老龄化加剧引致的劳动力短缺会通过工资竞争吸引邻地青壮年劳动力流入，使邻地同样面临劳动供给约束；反之，邻地老龄化带来的用工成本上升亦会沿产业链传导至本地。第二，市场需求渠道。相邻地区之间存在密切的产品与服务贸易联系，邻地因老龄化导致的消费结构变化与投资需求收缩会缩减本地企业的市场半径，削弱其规模经济与专业化分工水平[@shao2022]。第三，技术扩散渠道。技术进步具有典型的空间衰减特征，邻地创新活力下降会减少本地可获得的知识溢出与技术合作机会，进而拖累本地生产率增长[@shen2024]。基于此，本文提出：

假设2：人口老龄化对邻近地区全要素生产率具有显著的负向空间溢出效应。

## 1.3 作用机制与门槛特征

老龄化对全要素生产率的净影响是多重力量对冲的结果。一方面，老龄化通过降低劳动参与率直接收缩有效劳动投入，构成主导性的负向渠道。另一方面，依据诱致性技术创新理论，劳动力尤其是从事常规体力任务的中年劳动力相对稀缺会提高劳动的相对价格，促使企业以资本与自动化设备替代劳动，从而加快机器人等自动化技术的采用[@acemoglu2022;@acemoglu2018]；与此同时，在"数量—质量"权衡下，生育率下降会促使家庭增加人均教育投资，推动人力资本深化。这两条渠道均对老龄化的负面冲击形成部分对冲。

对冲能力的强弱取决于地区的技术基础。自动化替代与人力资本深化能否真正转化为生产率增长，取决于本地是否具备相应的研发能力、装备制造能力与技术吸收能力。在研发强度较低的地区，企业既缺乏自主开发替代性技术的能力，也难以有效吸收外来技术，老龄化引致的劳动短缺主要表现为产出损失；当研发强度跨越一定门槛后，自动化替代与技术升级的通道被打通，老龄化的抑制作用随之减弱；研发强度进一步提高并跨越更高门槛后，技术进步对劳动投入的替代弹性显著增大，抑制作用进一步收敛。基于此，本文提出：

假设3：人口老龄化通过降低劳动参与率抑制全要素生产率，同时通过诱致自动化替代与促进人力资本深化形成部分对冲。

假设4：人口老龄化对全要素生产率的抑制作用存在基于研发强度的门槛特征，随研发强度跨越门槛而依次减弱。

# 2 研究设计

## 2.1 空间权重矩阵

本文构建三类空间权重矩阵。基准矩阵$W_{1}$为0—1邻接矩阵，若两省份地理上接壤则元素取1，否则取0，海南省与广东省视为相邻。矩阵$W_{2}$为地理距离权重矩阵，元素取两省会城市间球面距离平方的倒数。矩阵$W_{3}$为经济地理嵌套矩阵，在地理距离矩阵的基础上按各省份样本期内城镇化率均值的相对规模对列加权。三类矩阵均作行标准化处理。

## 2.2 模型设定

首先采用全局Moran's *I*指数检验变量的空间自相关性：

$$I = \frac{n}{\sum_{i = 1}^{n}\sum_{j = 1}^{n}w_{ij}} \cdot \frac{\sum_{i = 1}^{n}\sum_{j = 1}^{n}w_{ij}(x_{i} - \bar{x})(x_{j} - \bar{x})}{\sum_{i = 1}^{n}(x_{i} - \bar{x})^{2}}\quad\quad（1）$$

其中，*n*为空间单元数，$w_{ij}$为空间权重矩阵的元素，$x_{i}$为待检验变量。

在确认空间相关性的基础上，构建时空双固定效应的空间杜宾模型：

$$\operatorname{lntfp}_{it} = \rho\sum_{j = 1}^{n}w_{ij}\operatorname{lntfp}_{jt} + \beta_{1}\operatorname{aging}_{it} + \theta_{1}\sum_{j = 1}^{n}w_{ij}\operatorname{aging}_{jt} + \beta_{k}\operatorname{Controls}_{it} + \theta_{k}\sum_{j = 1}^{n}w_{ij}\operatorname{Controls}_{jt} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（2）$$

其中，$\operatorname{lntfp}_{it}$为省份*i*在年份*t*全要素生产率的对数，$\operatorname{aging}_{it}$为人口老龄化水平，$\rho$为空间自回归系数，$\theta$为解释变量空间滞后项的系数，$\mu_{i}$与$\delta_{t}$分别为省份与年份固定效应。模型采用拟极大似然法估计。需要说明的是，对面板数据作时期去心变换会消去行标准化权重矩阵中对应特征值1的方向，因此本文按Lee和Yu（2010）[@leeyu2010]的建议，在雅可比行列式中剔除该特征值并相应调整有效样本量，以避免空间自回归系数的估计出现系统性偏误。

由于空间杜宾模型中解释变量的系数并不等于其边际效应，本文按LeSage和Pace（2009）[@lesage2009]的偏微分法进行效应分解。对第*k*个解释变量，其偏导数矩阵为：

$$S_{k}(W) = (I_{n} - \rho W)^{- 1}(\beta_{k}I_{n} + \theta_{k}W)\quad\quad（3）$$

直接效应取$S_{k}(W)$主对角线元素的均值，总效应取其所有元素的行和均值，间接效应为二者之差：

$$\operatorname{Direct}_{k} = \frac{1}{n}\operatorname{tr}\left[S_{k}(W)\right],\quad \operatorname{Total}_{k} = \frac{\beta_{k} + \theta_{k}}{1 - \rho},\quad \operatorname{Indirect}_{k} = \operatorname{Total}_{k} - \operatorname{Direct}_{k}\quad\quad（4）$$

各效应的标准误由参数估计量的渐近分布中抽取2000次模拟样本计算得到。

为识别老龄化影响的非线性特征，以研发强度为门槛变量构建面板门槛模型[@hansen1999]：

$$\operatorname{lntfp}_{it} = \eta_{1}\operatorname{aging}_{it}I(\operatorname{rd}_{it} \leq \gamma_{1}) + \eta_{2}\operatorname{aging}_{it}I(\gamma_{1} < \operatorname{rd}_{it} \leq \gamma_{2}) + \eta_{3}\operatorname{aging}_{it}I(\operatorname{rd}_{it} > \gamma_{2}) + \eta_{k}\operatorname{Controls}_{it} + \mu_{i} + \delta_{t} + \varepsilon_{it}\quad\quad（5）$$

其中，$\gamma_{1}$与$\gamma_{2}$为待估门槛值，$I( \cdot )$为示性函数；产业结构等控制变量的选取参照秦建群等（2022）[@qin2022]。为避免遗漏空间关联导致的偏误，控制变量中额外纳入邻近地区老龄化水平。门槛效应的显著性采用在原假设成立的模型下重复抽样的自助法检验。

## 2.3 变量选取与数据说明

**被解释变量。**全要素生产率（*lntfp*）。参考邱子迅和周亚虹（2021）[@qiu2021]的做法，以资本存量、从业人员数与实际地区生产总值为投入产出指标，运用DEA-Malmquist指数法测算各省份历年的全要素生产率变动，并以2010年为基期逐年累乘得到累积指数，取对数进入回归。

**核心解释变量。**人口老龄化（*aging*），以65岁及以上人口占常住人口的比重（%）衡量。

**门槛变量。**研发强度（*rd*），以研究与试验发展经费内部支出占地区生产总值的比重（%）衡量。

**机制变量。**劳动参与率（*lfp*，%）、机器人渗透度（*robot*，台/万人）与人力资本（*hc*），后者以6岁及以上人口的平均受教育年限衡量。

**控制变量。**城镇化率（*urban*，%）；产业结构（*stru*），以第三产业增加值占地区生产总值的比重（%）衡量；对外开放（*open*），以进出口总额占地区生产总值的比重衡量；政府干预（*gov*），以一般公共预算支出占地区生产总值的比重衡量；基础设施（*infra*），以人均城市道路面积取对数衡量；金融发展（*fin*），以年末金融机构各项贷款余额占地区生产总值的比重衡量。为避免与被解释变量之间的机械相关，本文未将人均地区生产总值纳入控制变量。

**工具变量。**以1982年第三次全国人口普查各省份0—14岁人口占比的标准化值与时间趋势的交乘项作为老龄化的工具变量。历史少儿人口结构通过人口世代更替决定当期老龄化水平的相对高低与演进速度，满足相关性要求；在控制省份与年份固定效应及一系列时变特征后，四十余年前的人口年龄结构难以直接影响当期全要素生产率，满足外生性要求。

样本涵盖2011—2023年中国30个省份（不含西藏及港澳台地区），共390个观测值，其中东部11个、中部8个、西部11个。指标口径参照《中国统计年鉴》《中国人口和就业统计年鉴》《中国科技统计年鉴》与国际机器人联合会数据设定。主要变量的描述性统计见表1。

# 3 实证结果与分析

## 3.1 空间相关性检验

## 3.5 内生性处理

参照江艇（2022）[@jiangting2022]提出的两步法，本文仅检验人口老龄化对机制变量的因果效应，机制变量与全要素生产率之间的关系依据理论与既有文献予以论证。表9第（1）至第（3）列显示，老龄化对劳动参与率的系数为−0.6311，对机器人渗透度的系数为0.3205，对人力资本的系数为0.0427，三者均在1%的水平上显著。这表明：老龄化率每提高1个百分点，劳动参与率下降0.63个百分点，构成抑制生产率的主导渠道；与此同时，机器人渗透度提高0.32台/万人、平均受教育年限延长0.04年，印证了Acemoglu和Restrepo（2022）[@acemoglu2022]的诱致性创新假说与"数量—质量"权衡机制。结合既有研究关于劳动投入收缩降低产能利用效率、自动化替代与人力资本深化提升生产率的结论[@wang2020;@dauth2021;@maestas2023]，可以认为老龄化的净效应是负向渠道占优、正向渠道部分对冲的结果，假设3得到验证。

# 4 结论与建议

## 4.1 研究结论

本文基于2011—2023年30个省份的面板数据，运用空间杜宾模型与面板门槛模型考察了人口老龄化对全要素生产率的影响。主要结论如下：第一，我国省域全要素生产率与人口老龄化均存在显著的正向空间自相关，LM检验、Hausman检验、LR检验与Wald检验一致支持时空双固定效应的空间杜宾模型设定。第二，效应分解显示，老龄化率每提高1个百分点，本地全要素生产率下降1.53%，邻近地区下降2.66%，总效应为下降4.18%，间接效应约为直接效应的1.74倍，忽略空间溢出会严重低估老龄化的生产率损失。第三，更换三类空间权重矩阵、替换被解释变量、缩尾处理、调整样本区间、动态空间杜宾模型以及基于历史人口结构工具变量的两阶段最小二乘与控制函数法检验均支持上述结论；控制函数项不显著，说明在控制双固定效应与一系列时变特征后，老龄化的内生性问题并不严重。第四，老龄化的抑制作用存在基于研发强度的双重门槛，门槛值为1.2786%与2.2323%，三个区制的系数依次为−0.0265、−0.0203与−0.0109，高研发强度区制的抑制作用仅为低研发强度区制的41.13%。第五，老龄化通过降低劳动参与率抑制生产率，同时诱致自动化替代与人力资本深化形成部分对冲；抑制作用在西部地区最强、东部地区最弱，与三大区域研发强度的排序恰好相反。

## 4.2 政策建议

第一，将应对人口老龄化的政策设计置于跨区域协同的框架之中。鉴于老龄化的生产率损失主要以空间外溢的形式实现，单一省份的应对措施难以内部化其全部收益，应在城市群与经济区层面统筹推进养老服务体系共建、劳动力市场一体化与产业链协同布局，避免各地在劳动力争夺中形成"以邻为壑"的负和竞争。

第二，把提升研发强度作为对冲老龄化冲击的战略着力点。门槛检验表明，研发强度跨越1.28%与2.23%两个临界值后，老龄化的抑制作用显著减弱。对研发强度仍处于第一区制的省份，应通过财政科技投入引导、研发费用加计扣除与创新平台建设等方式尽快推动其跨越第一门槛；对已进入第二区制的省份，则应着力提升研发投入的质量与转化效率，争取跨越第二门槛。

第三，畅通自动化替代与人力资本深化两条对冲渠道。一方面，加大对智能制造与工业机器人应用的支持力度，重点面向劳动力短缺突出的行业推广"机器换人"，同时完善劳动者转岗培训与社会保障衔接；另一方面，持续提高教育投入与职业技能培训的覆盖面，以人力资本质量的提升弥补劳动数量的不足，并通过渐进式延迟退休、发展银发经济等举措挖掘老年人力资源潜力，缓解劳动参与率的下行压力。

第四，实施区域差异化的应对策略。西部地区老龄化的生产率损失最为严重且研发基础薄弱，应通过中央财政转移支付、东西部科技协作与人才定向支持等方式加快其技术能力建设；东部地区则应发挥技术优势，在自动化替代与老龄产业创新方面先行先试，并通过技术扩散带动中西部地区的能力提升。

本文尚存在可拓展之处：受省级数据可得性限制，本文未能刻画老龄化影响的行业异质性与企业层面微观机制；此外，空间权重矩阵的设定虽已作多重稳健性检验，但劳动力流动网络等社会经济联系矩阵可能提供更贴合理论机制的空间结构，有待后续研究进一步探索。
