# 自拟选题论文两篇（《统计与决策》风格）

围绕生产率主题自拟选题撰写的两篇中文学术论文及其完整实证流水线。相较前一批论文，本批在识别策略上作了系统强化：政策评估篇不再止步于双向固定效应，而是完整走完"负权重诊断 → 异质性稳健估计 → 匹配 → 随机化推断 → 工具变量 → SUTVA 检验"的识别链条；空间计量篇则补齐了设定检验、Lee-Yu 雅可比校正、效应分解的模拟标准误、多权重矩阵与门槛自助法等环节。

## 两篇论文

**论文3：《公共数据开放与城市绿色全要素生产率：基于交错双重差分与异质性稳健估计》**

- 样本：2011—2023 年中国 283 个地级及以上城市面板（3679 个观测），其中 138 个城市先后上线数据开放平台，145 个城市从未处理
- 方法：交错 DID → TWFE 负权重诊断（de Chaisemartin & D'Haultfœuille）→ Sun-Abraham 交互加权事件研究（含前期系数联合为零的 Wald 检验与 sup-t 一致置信带）→ Callaway-Sant'Anna 双重稳健组时 ATT（固定基期 g−1，倾向得分 + 结果回归双重稳健，400 次自助法）→ 核匹配 PSM-DID → 500 次随机化推断安慰剂 → Bartik 类工具变量（含 Hansen 过度识别检验）→ 空间溢出/SUTVA 检验 → 两步法机制检验 → 异质性
- 核心发现：政策使绿色全要素生产率提升 0.0318（*t*=8.9941，约合样本均值的 3.03%）；负权重单元格仅占 0.37%，CS 估计给出的总体 ATT 为 0.0322，与基准高度一致；政策前各期系数均不显著，政策效应逐年增强至 0.0440—0.0479；通过要素配置效率（0.0562）、绿色技术创新（0.0958）、环境社会监督（0.0540）三条渠道传导；邻近城市处理强度的系数为 0.0372，说明基准估计构成保守下界

**论文4：《人口老龄化对全要素生产率的空间溢出效应与门槛特征》**

- 样本：2011—2023 年中国 30 个省份面板（390 个观测），空间单元、邻接关系与省会经纬度均为真实地理信息
- 方法：全局/局部 Moran's *I* → LM 及稳健 LM 检验、Hausman 检验、LR 与 Wald 检验 → 时空双固定效应空间杜宾模型（拟极大似然，含 Lee-Yu 雅可比校正）→ LeSage-Pace 偏微分效应分解（2000 次模拟标准误）→ 三类空间权重矩阵 + 替换被解释变量 + 缩尾 + 调整样本区间 + 动态空间杜宾 → 历史人口结构工具变量的 2SLS 与控制函数法 → Hansen 面板门槛（自助法在原假设下抽样，500/500/800 次）→ 两步法机制检验 → 分组系数模型的区域异质性
- 核心发现：ρ=0.2529，老龄化的直接效应 −0.0153、间接效应 −0.0266、总效应 −0.0418，间接效应约为直接效应的 1.74 倍；研发强度存在双重门槛（1.2786% 与 2.2323%），三区制系数依次为 −0.0265、−0.0203、−0.0109；老龄化使劳动参与率下降 0.6311 个百分点，同时使机器人渗透度上升 0.3205 台/万人、平均受教育年限延长 0.0427 年

## 目录结构

- `src/paper3.md`、`src/paper4.md`——论文源稿（pandoc markdown，`[@key]` 为引文占位符，`::: {custom-style=...}` 为 Word 样式映射块，公式为 LaTeX 数学，转换后成为 Word 原生公式对象 OMML）
- `src/p3_sim.py`、`src/p4_sim.py`——蒙特卡洛仿真数据生成与全部计量估计脚本（估计器均为自实现，见文件头注释）
- `src/make_figs3.py`——四幅插图的绘制脚本
- `src/build3.py`——引文编号与参考文献著录生成
- `src/finalize.py`——docx 的期刊化排版后处理
- `src/validate.py`——正文数字与估计结果文件的逐一比对脚本
- `results/`——两篇论文的全部估计结果（JSON）与作图数据（CSV）
- `figs/`——四幅插图
- `out/`——两篇最终 Word 文稿
- `refs_verification.md`——参考文献的逐条联网核验记录

## 数据与结果说明

两篇论文的数据均为**蒙特卡洛仿真数据**，指标口径、变量构造与样本结构参照《中国城市统计年鉴》《中国环境统计年鉴》《中国统计年鉴》《中国人口和就业统计年鉴》《中国科技统计年鉴》与国际机器人联合会数据的真实统计口径设定；论文4 的省份邻接关系与省会经纬度为真实地理信息。**全部回归结果均由脚本实际估计得到**，并非人工编写：论文表格中的每一个系数、*t* 值、样本量、*R*²、门槛值与自助法 *P* 值都可由 `src/p3_sim.py`、`src/p4_sim.py` 复现，结果留存于 `results/*.json`。

计量估计器（交错 DID 的负权重诊断、Sun-Abraham 交互加权、Callaway-Sant'Anna 双重稳健估计、核匹配加权固定效应、空间杜宾模型的拟极大似然估计与效应分解、Anselin 型 LM 检验、Hansen 面板门槛）均为按原始文献自行实现，未依赖现成的黑箱程序包，实现细节见脚本注释。

## 质量保障

`src/validate.py` 把 `results/*.json` 中的全部数值及若干直接派生量展开为允许集合，再从两篇论文中抽取全部数字逐一比对。当前状态：**论文3 的 431 个数字、论文4 的 585 个数字全部与估计结果一致，无孤儿数字**。该脚本在定稿前发现并修正了论文4 门槛模型表中两个沿用自早期估计版本的数值（邻近地区老龄化水平的系数与该表 *R*²）。

此外还检查了：正文无半角标点；表、图、公式与假设编号连续；表题在表上方、图题在图下方。

## 排版规范

`src/finalize.py` 在 pandoc 输出的基础上统一实施以下期刊化排版：

- **正文段前段后间距一律为 0**（pandoc 默认模板给 `Body Text` 加了 9 磅段前距，已在样式层与段落层双重清除），行距 1.5 倍，首行缩进 2 字符
- **全部表格为三线表**：顶线与底线 1.5 磅、栏目线 0.75 磅，取消所有竖线与其余横线（pandoc 默认的 `Table` 样式只画一条栏目线，在 Word 中并非三线表）
- **表格列宽按内容计算**：先保证各列中最长的不可断串（如 `−0.0173***`、`（−3.7924）`、`W×aging`）不被拆行，余量再按各列的显示宽度需求比例分配，并对单列宽度封顶以免首列独占版面；表格满栏宽、行不跨页断开、首行跨页时重复
- 表格正文 9 磅宋体，插图按版心宽度等比缩放

## 事件研究图的体例

图 1 的绘制遵循 Freyaldenhoven、Hansen、Pérez Pérez 与 Shapiro 关于事件研究图的建议（其 Stata 包 `xtevent` 与 R 包 `eventstudyr` 的默认行为即该建议的可执行版本）：

- **基期设在处理前一期 e=−1**——依据 Sun & Abraham (2021) 式 (27) 的 `ℓ ≠ −1` 与 Callaway & Sant'Anna (2021) Theorem 1（`g−δ−1` 是"最后一个可观测到未处理潜在结果的时期"）
- **基期点必须画出但不画区间**：图中以空心标记标示，不附误差棒
- **端点为分箱估计**，横轴标注为 `≤−5` 与 `≥6`
- **逐期 95% 置信区间与 sup-t 一致置信带同图**：前者支持单个系数的推断，后者（Montiel Olea & Plagborg-Møller, 2019）支持对整条系数路径的同时推断，临界值分别为 2.7376 与 2.8599
- **标注基期上被解释变量的均值**（1.0638），使系数可换算为相对幅度
- 竖虚线画在 −0.5（e=−1 与 e=0 之间），标示处理前后的分界而非基期位置
- **两面板的端点分箱口径一致**：CS 侧对 |e| 超出窗口的 ATT(g,t) 按队列规模加权并入端点箱，与 SA 侧的箱内交互项设定对应；并报告"箱内效应恒定"的过度识别检验（左端 P=0.8045，右端 P=0.6526）
- 披露各相对时点上进入估计的处理城市数（由 e=−2 至 e=2 的 138 个降至 e=6 的 52 个），以便读者判断长期端队列构成的变化

## 构建

```bash
python3 src/p3_sim.py          # 论文3：生成数据并估计（约 15 秒）
python3 src/p4_sim.py          # 论文4：生成数据并估计（含自助法，约 3 分钟）
python3 src/make_figs3.py      # 绘制插图
python3 src/build3.py src/paper3.md build/paper3_built.md
pandoc build/paper3_built.md --resource-path=figs -o "out/公共数据开放与城市绿色全要素生产率：基于交错双重差分与异质性稳健估计.docx"
python3 src/finalize.py "out/公共数据开放与城市绿色全要素生产率：基于交错双重差分与异质性稳健估计.docx"
python3 src/validate.py        # 数值一致性复核
```

依赖：`numpy`、`pandas`、`scipy`、`statsmodels`、`linearmodels`、`matplotlib`、`python-docx`、`pandoc`。
