# 用词、标点与常被误用的术语

作为收紧用词、修标点、核查某个术语时的速查表。(句子级/词语级的*原则*在
`prose-craft.md`;本文件是参考表。)忌用词与标点针对**英文写作**——这正是你投稿要用的语言。

## 简洁:把臃肿短语换掉

删清嗓子和啰嗦短语。右列通常就是全部修法。

| 避免 | 改用 |
|---|---|
| it should be noted that / it is important to note that / it was found that | (删) |
| it is apparent that / it appears that | apparently |
| it may be that | I think |
| the results indicate that / is shown to be | (删) / *the results show* |
| due to the fact that / in spite of the fact that | because / even though |
| despite the fact that | although |
| in order to | to |
| for the purpose of / with the purpose of | to |
| in the event that | if |
| in a number of cases | some |
| a greater number of | more |
| in terms of | by, in(或重写) |
| in the vicinity of / on the order of / more or less / with respect to / in reference to | about, near |
| through the use of | by, with |
| is equal to | is |
| utilize · perform · initiate · facilitate · propagation · methodology | use · do · start · cause · movement · methods |

**冗余对**(去掉括号词):(absolutely) essential · (completely) eliminate · (end)
result · (final) outcome · (general) overview · (past) experience · period (of
time) · (model) simulation · smaller (in size) · (very) unique · variety of
(different) · (basic) fundamentals · (currently) underway · never (before) ·
(already) existing。

另外:别把 *about* 打扮成"approximately / in the vicinity of / more or less"。不需要
介绍的图就别介绍——描述科学、括号引图。

## 精确:把疲软的词换成具体内容

**疲软名词**(松散使用会损精确):ability, activity, analysis, approach, case,
character, concept, context, degree, development, dynamics, effect, element,
environment, event, factor, forcing, influence, interaction, issue, level, manner,
nature, perspective, process, relationship, role, sense, situation, system, thing,
use。

**空洞形容词/副词:** actually, basically, certain(ly), clear(ly), current(ly),
extreme(ly), feel, important, interesting, kind of, naturally, now, obvious(ly),
of course, practically, quite, recent(ly), regarding, soon, still, type of,
various, very, wish。

→ 删 *very/quite*;不要断言"interesting"/"important"——说明**为何**;禁用 *feel*(科学靠
事实);把模糊时间词(*recently/now*)换成日期。用具体之物替换疲软名词,或在首次使用时
精确定义。

**需要证据的最高级/绝对词:** first, novel, pioneering, comprehensive, detailed,
always, never, best。每个都用计数、引用或数据支撑,否则删。

## 标点

### 逗号
- 隔开**引导性**词/短语/从句("Therefore, …";"On the other hand, …";"Flying through
  the cloud deck, the aircraft …")。检验:删掉它句子仍成立,就用逗号。(但动名词/不定式
  短语作主语时,与谓语之间不加逗号:"Choosing a wavelet is crucial"——无逗号。)
- 用逗号 + 连词连接两个**独立分句**("…captured the structure, **and** the
  high-resolution output captured the gust front");短分句可省。
- 用逗号隔开**非限制性**(常以"which")短语;**限制性**("that")短语不加。("…within
  1–2 dB, **which** is sufficient…" vs. "…estimate **that** brings the radar within
  1–2 dB is sufficient…")
- 隔开**列表项**;多数期刊加**系列(牛津)逗号**。隔开**城市, 州**("Green Bay,
  Wisconsin, receives…")。

### 连字符
- 拼写的数字(twenty-nine);名词前的复合修饰语("cloud-to-ground lightning",
  "500-hPa wind" 但 "the wind at 500 hPa");单个大写字母 + 名词(X-ray)。
- 悬挂连字符:"lower- and upper-level anomalies","700-, 500-, and 300-hPa
  temperatures"。
- *-ly* 副词后**不**加连字符("widely used scheme")——但名词前"well-known equation",
  对比之后"the equation is well known"。
- 前缀一般不加连字符(reexamine, nonlinear, postfrontal),除非接专有名词
  (trans-Atlantic)、造成三连字母(shell-like)、或意为"前"(ex-hurricane)。为消歧加
  (re-count vs. recount)。用法会漂移(两词 → 连字符 → 一词);拿不准查期刊风格、词典或
  Chicago 手册。

### 短破折号(–)vs. 长破折号(—)
- **短破折号(en dash)**连接对等项、范围、一方为两词的复合形容词;**两侧不加空格**:
  "NCEP–NCAR reanalyses","1970–1999","Kain–Fritsch scheme","30%–70%","pp.
  112–119","air–sea interaction","Nobel Prize–winning"。也作减号(−14°C)。LaTeX 中
  用 `--`。
- **长破折号(em dash)**用于隔开对照信息、举例或插入——像这样——比短破折号长。

## 常被误用的术语

一长串**学科专有**清单——具体术语请用户深入调查(convective temperature、
difluence vs. divergence 等)。几条可迁移到任何领域:

- **Accuracy vs. skill** —— *accuracy* = 预报/预测与观测的吻合;*skill* = 相对某基准的表现。
  预测可以准确却无技巧,反之亦然。
- **Causing / "causes"** —— 我们很少真知道因果链,多是推断。优先用 **"associated with"**,
  除非你能为因果辩护。(统计关联 ≠ 因果。)
- **Correlate / correlation** —— 保留给数学意义(相关系数)。否则用 **relate, relation,
  correspond, association**。
- **Chaos / random** —— 都有精确技术含义;别随意用来指"杂乱"——说 *disorganized*。
- **Significant / significance** —— 暗示做过**统计**检验。别用来仅表示"大"或"可观"。
- **Data** —— 复数("the data **are**";单数 *datum*,但"data point"更顺)。在区分要紧的
  领域,**data** 留给观测,而非模式输出。
- **Date vs. day** —— "the **date** of the event was 9 February",不是"the day"。
- **Dates/times** —— 用无歧义格式;绝不用"12/10/94"(12 月 10 日还是 10 月 12 日?)。
- **Theory** —— 有很强的技术含义;别松散地用来指猜测或假设。

当一个词有精确的学科含义,优先用精确的词并在首次出现时定义;术语一致是好学术的一部分。
