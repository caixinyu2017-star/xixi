# 结果呈现规范

表、图、文字三块。目标是"审稿人看一眼就知道你做了什么、样本多大、标准误怎么算的"。

---

## 一、回归表

### 结构

- **三线表**：顶线、表头下横线、底线。**不画竖线**，不画每行的横线。
- 列 = 模型设定，按"只有核心变量 → 加控制 → 加固定效应"递进
- 行 = 变量，核心解释变量排第一行
- 系数下方括号里放**标准误**（不是 t 值；若放 t 值必须在表注说明）
- 显著性星号统一用 `* p<0.1, ** p<0.05, *** p<0.01`，并在表注写明

### 表底必须有的行

| 行 | 说明 |
|---|---|
| Observations | 样本量。各列不一致时必须在表注解释为什么 |
| R² / Within R² | 固定效应模型报 within R² 并注明 |
| 固定效应 | 每一层用 Yes/No 标出（Individual FE、Year FE …） |
| Controls | Yes/No |
| Clusters | 聚类单元数。**少于 30–50 个时必须提示可能需要 wild bootstrap** |

### 表注必须交代

1. 标准误在什么层级聚类
2. 显著性标记的阈值
3. 控制变量具体包含哪些（或指向哪个附表）
4. 样本筛选规则
5. 变量单位与是否取对数

### 数字格式

- 系数与标准误保留位数一致，通常 3 位小数
- 系数量级过小时（如 0.0001）改变量单位，不要靠加小数位
- 千分位分隔符用于样本量（12,345）
- **不要给出计算精度之外的位数**

---

## 二、Table 1 描述统计

- 连续变量：N、Mean、SD、Min、P50、Max
- 分类变量：频数与百分比
- 有处理组/对照组时：分组统计 + 组间差异 + 差异检验的 p 值
- 变量顺序：被解释变量 → 核心解释变量 → 控制变量，与回归表一致
- 每个变量给中文/英文全称与定义，不要只给缩写列名

---

## 三、图

图**一律交给 `nature-figure` 用 Python/R 绘制**，禁止用生成式图像模型画带真实数据的图。

传给 `nature-figure` 时要说清楚：

| 项 | 内容 |
|---|---|
| 结论 | 这张图要让读者看出什么（一句话） |
| 数据源 | 哪个结果文件、哪几列 |
| 图型 | 事件研究图 / 系数森林图 / 分组柱状 / 密度重叠 / 热图 |
| 规格 | 目标期刊、单栏还是双栏、导出格式（PDF/TIFF 300dpi/SVG） |

### 事件研究图的固定要求

- 横轴为相对处理时间，基准期（通常 -1）系数固定为 0 并在图上标出
- 每期给点估计 + 95% 置信区间
- 处理时点画竖虚线
- 处理前各期若显著，必须在正文里正面讨论，不能只放图不说

### 通用要求

- 坐标轴必须有标签和单位
- 误差棒必须说明是标准误还是置信区间、几个百分点
- 配色对色盲友好，且黑白打印后仍可区分（靠形状/线型冗余编码，不只靠颜色）
- 图注自足：只看图注就能知道样本、设定、标准误

## 四、结果文字

### 一段标准的结果描述包含

1. **这一列/这张表在估什么**（一句话）
2. **系数的符号、大小、显著性**
3. **经济意义**：换算成"处理组比对照组高 X%"或"1 个标准差的变化对应 Y 个标准差"
4. **与预期/文献的关系**

示例结构：

> 表 3 第 (3) 列在同时控制个体与年份固定效应后，`treat` 的系数为 0.083（标准误 0.031），
> 在 1% 水平上显著。以被解释变量样本均值 1.24 为基准，这意味着政策实施使 <…> 提高约 6.7%，
> 相当于 0.21 个标准差。该量级与 <文献> 报告的 <…> 接近。

### 语言纪律

- 相关性研究不要写"导致""促进""影响"，写"与……正相关"
- 不显著就写不显著；不要写"存在一定的正向趋势""边际显著"（p=0.11 不是边际显著）
- 不要用"结果非常显著""高度显著"——显著性是二元判断加阈值，不是程度副词
- 不要把"系数大"说成"效应强"而不换算经济意义
- 稳健性做了几项就说几项，不要写"经过一系列稳健性检验后结论依然成立"而不列出是哪些

### 交付给写作技能

结果段落草稿写完后：

- 要从零起草整段/整节 → `nature-writing`
- 已有草稿要润色成期刊英语 → `nature-polishing`
- 需要补文献支撑 → `nature-citation` / `nature-academic-search`

## 五、可复现性

交付时给出：

```
analysis/
├── 01_clean.py        # 原始数据 → 分析样本
├── 02_descriptive.py  # Table 1
├── 03_baseline.py     # Table 2 基准回归
├── 04_robust.py       # Table 3 稳健性
├── 05_mechanism.py    # Table 4 机制与异质性
├── 06_figures.py      # Figure 1-3（或交给 nature-figure）
└── README.md          # 运行顺序、依赖版本、每张表图对应哪个脚本
```

随机过程（bootstrap、置换检验、匹配）必须设种子并在脚本里写死。

数据可得性声明、仓储选择、accession number → `nature-data`。
