# The Vanishing First Rung

Manuscript and full replication package for a submission to the MDPI journal **Systems**,
Special Issue *"Systems Approaches to Generative AI: Workforce Development, Organisational
Learning, and Economic Transformation"* (Guest Editor: Dr. Ali Ahsan; deadline 30 April 2027).

**Title:** The Vanishing First Rung: Generative Artificial Intelligence, Entry-Task Exposure
and Youth Employment in Chinese Listed Firms

## ⚠ Read this before submitting

This container had **no outbound network access**, so the CSMAR / WIND extraction described
in Section 3.1 of the manuscript could not be performed. `data/panel.csv` is a **calibrated
synthetic panel**:

* firm-level control variables are drawn to reproduce the published descriptive moments of
  comparable Chinese A-share samples;
* sample size, period and unbalancedness follow the same sources;
* the outcome and treatment variables are generated by the documented data-generating
  process in `data/make_panel.py`, whose coefficients are set from published effect sizes in
  the generative-AI labour literature.

Every number in every table and figure is **genuine output of the estimation code run on that
panel** — nothing is transcribed by hand or invented. But they are estimates of a simulated
process, not measurements of firm behaviour. The manuscript states this in Section 3.1, in the
Limitations (Section 5.3) and in the Data Availability Statement.

**To finish the paper:** replace `data/panel.csv` with the real extraction (same column names)
and re-run `analysis/estimate.py`, `analysis/figures.py`, `build/build_paper.py`. No estimation
code needs to change.

## Design at a glance

* **Question:** did the diffusion of generative AI narrow the entry rung of the firm-internal
  job ladder, and what determines the size of the loss?
* **Framing:** the firm as a socio-technical system; GenAI raises the productivity of the
  technical subsystem while degrading the reproduction function of the social subsystem,
  because the tasks it absorbs are simultaneously production input and training input.
* **Identification:** continuous-treatment difference-in-differences around the late-2022
  arrival of general-purpose LLM assistants, with treatment intensity given by each firm's
  pre-shock exposure to routine cognitive entry tasks. 31,015 firm-years, 3,240 firms,
  2014–2024.
* **Hypotheses:** H1 direct effect; H2a entry-task restructuring channel; H2b training
  channel; H3a organisational learning capacity moderates; H3b internal labour-market depth
  moderates.

## Reproducing

```bash
pip install numpy scipy pandas matplotlib statsmodels linearmodels scikit-learn python-docx
python3 data/make_panel.py          # -> data/panel.csv
python3 analysis/estimate.py        # -> tables/*.csv, analysis/out/*.csv
python3 analysis/figures.py         # -> figures/fig3..fig7 (legends below the plot)
python3 build/build_paper.py        # -> The_Vanishing_First_Rung.docx
python3 build/build_cover_letter.py # -> Cover_Letter.docx
```
