```

├─ data/
│   ├─ facts.md          核实过的公开统计口径（每条标注来源与发布日期）
```

## 三、数据说明（重要）

**城市层面的跨省异地就医结算明细与医院财务明细目前不对外公开。**
本文的分析样本是按 `data/facts.md` 中记录的公开口径**校准生成的模拟面板**，
用途是完整、可复现地展示识别策略与推断链条，而非报告对现实参数的最终估计。
这一点在论文正文的数据小节与脚注中已明确声明。

用于校准的公开锚（均可回溯到国家医保局与国家卫生健康委的正式发布）：

## 四、变量与估计

**处理**：城市首次接入门诊费用跨省直接结算的年份（2019—2023 分批）。

**结果变量**：跨区就医占比、本地次均住院费用（对数）、
外地—本地次均费用比（对数，即"费用缺口"）、本地住院率、
医院加成率、基金外流率、三级医院外地患者收入占比、基层诊疗量占比。

**估计量**：
1. 双向固定效应交错 DID（城市层面聚类）
2. 事件研究（基期为改革前一年）与事前趋势联合检验
3. 以尚未接入城市为比较组的群组—时期估计量，按处理组规模聚合
4. 按群组规模加权的交互加权估计量
5. 加入城市特定线性时间趋势
6. 控制同期改革（门诊共济、按病组／病种分值付费）
7. 更换聚类层级（城市 → 省份）
8. 随机化处理年份 500 次的安慰剂检验
9. 以高铁通达度×改革为工具变量的两阶段估计
