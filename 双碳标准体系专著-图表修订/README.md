## 生成方式

所有图片使用 image2 模型（`gpt-image-2`，经 chedankj.com API）按逐图撰写的版式规范生成：

- `scripts/figspec.py`：17 张图的完整生成规范（版式、文字、连线逐一指定）
- `scripts/run_gen.py`：批量生成驱动（并行调用 + 重试）
- `scripts/replace_imgs.py`：将新图替换进 docx 对应媒体位置并按新图宽高比更新版式尺寸
- `figures/`：最终采用的 17 张图（PNG）
