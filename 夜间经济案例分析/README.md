——基于嘉兴市戴梦得商贸集团有限公司夜间经济实践

## 交付物

| 文件 | 说明 |
| --- | --- |
| `夜间经济场景理论案例分析_修订稿.docx` | 定稿（正文全部新增／修改文字以红色显示） |
| `夜间经济场景理论案例分析_修订稿（预览）.pdf` | 排版预览（由 LibreOffice 导出，共 72 页） |

## 结构

- 封面 / 摘要与关键词 / 目录（Word 域，打开后右键“更新域”生成）
- 第一章 绪论（研究背景、研究问题、国内外研究述评、目的与意义、案例选取、方法与技术路线、理论基础与分析框架）
- 第二章 案例对象介绍（企业概况、发展历程、荣誉资质、案例情境、代表性分析）
- 第三章 案例呈现：真／美／善三维场景营造实践与“嘉夜场景”模型
- 第四章 案例分析：三维作用机理、闭环机理与形式化刻画（式 4-1 至 4-10）
- 第五章 案例总结与启示（结论、理论贡献、实践启示、可推广性与适配条件、局限与展望）
- 参考文献（GB/T 7714 顺序编码制，18 条）
- 附录 半结构化访谈提纲

## 排版规范

- 章标题：黑体小三加粗；节标题：黑体四号；条标题：黑体小四
- 正文：宋体小四，1.5 倍行距，首行缩进 2 字符，无段前段后间距
- 图名置于图下（五号黑体），表名置于表上（五号黑体），表格统一为三线表
- 公式使用 Word 自带公式编辑器（OMML）对象，居中排版，编号右顶格
- 参考文献按正文首次引用顺序连续编码，正文引用与文后著录一一对应
