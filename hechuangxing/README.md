# 禾创星 · 嘉兴本地化创业智能体

一款面向嘉兴本地大学生与小微初创企业的创业智能体：上传创业计划书或直接说思路，它先判断这个方案在嘉兴能不能吃到政策，够不上就直接说够不上，然后给出把方案改造成能享受政策的版本，并一键导出两份排版合规的 Word。

文化底色是嘉兴南湖的红船精神与海盐步鑫生的改革创业精神。

---

## 一、三分钟跑起来

### 第 0 步：先装 Python（只需一次）

打开 <https://www.python.org/downloads/> 下载安装包运行。
**安装第一屏一定要勾选 Add python.exe to PATH**，不勾后面会报找不到 Python。
需要 3.10 或更高版本。已经装过就跳过这步。

### Windows

双击 `start.bat`（或 `启动.bat`，两个是同一个文件）。

首次运行会自动创建环境并安装依赖，大约 1 到 2 分钟，
窗口停着不动是正常的，不要关。装完会自动打开浏览器。

### macOS / Linux

```bash
cd hechuangxing
./start.sh
```

### 手动启动（任何系统）

```bash
python3 start.py
```

或者自己建环境：

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python server.py
```

### 启动脚本会自动处理的几件事

- 检测 Python 是否安装，没装就给出下载地址和勾选提示
- 创建虚拟环境并安装依赖；官方源装不上时自动换清华、阿里云镜像重试
- 生成 `.env` 配置文件
- 等服务真正起来再打开浏览器，不会出现打不开的空白页
- 端口 8848 被占用时自动往后找一个能用的端口

> **注意**：`.bat` 文件内部是纯英文的。Windows 的 cmd 读带中文的批处理文件会乱码
> 并导致命令执行失败，所以中文提示全部交给 `start.py` 打印。改这个文件时不要往里加中文。

## 二、要不要配 API Key

两种模式都能完整演示，区别只在回答是现场生成还是内置脚本。

| 模式 | 怎么进入 | 表现 |
| --- | --- | --- |
| 离线演示模式 | 默认就是（不填 Key） | 用内置的嘉兴案例脚本流式作答，两份 Word 用内置内容生成。断网也能跑，录屏零风险 |
| 实时模式 | 在 `.env` 里填 `ANTHROPIC_API_KEY` | 接 Claude 实时生成，回答与 Word 内容都按你上传的真实计划书现写 |

配置方法：打开 `.env` 文件（启动时自动生成），把这一行前面的井号去掉并填上你的 Key：

```
ANTHROPIC_API_KEY=sk-ant-你的key
```

用中转服务的话再去掉 `ANTHROPIC_BASE_URL` 那行的井号并填地址。

几个保险设计：

- Key 没填、或者原样留着占位符文字，都会被识别为没填，自动走离线演示模式，
  不会拿一个假 Key 去调接口然后在演示时报鉴权错误。
- 实时模式下如果调用失败（网络断了、Key 过期、额度用完），
  且还没输出任何内容，会自动切回离线演示脚本并在开头说明原因，演示不中断。
- 点生成 Word 时如果接口出错，也会退回内置内容，按钮点下去一定出得来文件。

**录屏建议**：先用默认的离线演示模式走一遍流程确认画面，正式录制时再决定要不要切实时模式。

## 三、界面怎么用

- **中间**：聊天区。左下角回形针按钮上传创业计划书，也支持直接把文件拖进窗口、或者截图后 Ctrl+V 粘贴。支持 `.docx`、`.pdf`、`.txt`、`.md` 和图片。
- **左栏**：全链条八个环节，点任意一个直接发出对应的问题；下面是当前加载的专属语料库清单。
- **右栏**：
  - **可下载交付物**：两个按钮分别生成《创业计划改进方案》和《全链条创业落地方案》Word，生成后在下方出现下载链接。
  - **政策雷达**：根据你说的内容实时命中政策，显示金额、层级与主管部门。
  - **示例文件**：三份预生成的 Word 样张，可直接下载查看排版效果。

**演示动线建议**：上传 `samples/测试用-网媒投稿发表公司创业计划书.docx` → 发一句「帮我看看这个方案能不能拿到嘉兴的政策，该怎么改」→ 等回答出完 → 点右侧两个按钮生成 Word → 打开 Word 展示排版。

## 四、Word 排版规范

两份输出文档与测试用计划书都按下列规范渲染，已通过逐段自动核验：

| 层级 | 中文字体 | 西文字体 | 字号 | 对齐 | 首行缩进 |
| --- | --- | --- | --- | --- | --- |
| 一级标题 | 黑体 | Times New Roman | 小三（15pt） | 居中 | 无 |
| 二级标题 | 黑体 | Times New Roman | 四号（14pt） | 左对齐 | 2 字符 |
| 三级标题 | 宋体加粗 | Times New Roman | 小四（12pt） | 左对齐 | 2 字符 |
| 正文 | 宋体 | Times New Roman | 小四（12pt） | 两端对齐 | 2 字符 |
| 表格 | 宋体 | Times New Roman | 五号（10.5pt） | 居中 | 无 |

正文与标题一律无段前段后间距；表格段前段后 0 磅、单倍行距、整表居中、表头跨页重复；首行缩进用 Word 的字符单位（`firstLineChars=200`），换字号不会走样；引号等标点跟随中文字体。

正文行距默认 1.5 倍（规范只对表格明确要求单倍行距）。要改成单倍，编辑 `hcx/docx_style.py` 里的一行：

```python
BODY_LINE_SPACING = 1.5   # 改成 1.0 即为单倍行距
```

自检命令：

```bash
./.venv/bin/python scripts/check_format.py
```

它会逐段核对字体、字号、对齐、缩进、段前段后与表格行距，输出问题清单。

## 六、禾创星和通用大模型的区别

通用大模型回答创业问题时给的是放之四海皆准的建议。禾创星强制走一套本地化的判断流程：

1. **政策适配性四问**：有没有自主知识产权；收入里有没有软件或技术成分；行业代码归到哪一类；能不能挂上嘉兴主抓的产业方向。四问过一遍，能拿什么、拿不到什么，一清二楚。
2. **敢下否定结论**：够不上就说够不上，缺哪个条件、怎么补，写明白。
3. **给数字不给形容词**：写清具体金额、比例、期限、主管部门与文件出处。
4. **给动作不给建议**：写清下周几、带什么材料、去哪个部门办。
5. **风险预警前置**：例如网媒投稿类业务，会先告诉你互联网新闻信息服务许可证普通商业公司拿不到，哪些活不能接。

## 八、常见问题

**上传 .doc 提示读不了？**
Word 旧版格式无法直接解析，在 Word 里另存为 .docx 再传，或者把正文粘贴到对话框。

**PDF 传上去是空的？**
扫描件没有文字层，提取不到内容。上传 Word 版本或粘贴正文。

**端口被占用？**
启动脚本会自动往后找一个能用的端口并在窗口里告诉你，直接看提示里的地址即可。
想固定端口就在 `.env` 里改 `HCX_PORT`。

**双击 bat 后窗口一闪而过？**
说明 Python 没装或没加进 PATH。在文件夹地址栏输入 `cmd` 回车，
在打开的窗口里敲 `python --version`：能显示版本号就再敲 `start.bat` 看报错；
提示不是内部或外部命令，就回第 0 步重装 Python 并勾选 Add python.exe to PATH。

**窗口里一堆乱码加上不是内部或外部命令？**
这是旧版启动脚本的问题（cmd 读不了带中文的 bat 文件），已经修好。
请重新下载最新代码。

**生成 Word 时报错？**
实时模式下多为 API Key 或网络问题，界面会把错误原文显示出来。把 `HCX_DEMO=1` 打开可立即切回离线演示模式继续演示。

**想换模型？**
改 `.env` 里的 `HCX_MODEL`。
