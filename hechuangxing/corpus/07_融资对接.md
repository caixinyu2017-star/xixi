# 一、融资的正确顺序

对嘉兴的学生创业者与小微初创企业，建议按下面的顺序取钱，成本由低到高：

1. **政府补贴与奖励**：不稀释股权、不用还。一次性创业补贴、创业社保补贴、场地租金补贴、创业带动就业补贴、人才生活补贴等。
2. **贴息贷款**：创业担保贷款个人最高 50 万元，在校大学生与毕业 5 年以内高校毕业生申请的按规定给予全额贴息，贴息期限不超过 3 年；其他人员按贷款合同签订日 LPR 减 150 个基点以上部分给予贴息。小微企业创业担保贷款额度更高。
3. **政府性融资担保＋银行信贷**：嘉兴推出科技创新保等产品，担保费率最低至 0.5%；科创企业贷款风险补偿池给予最高 1% 风险补偿，贷款贴息最高 40%。
4. **股权融资**：最后才考虑，且要在有收入、有数据之后。

# 二、创业担保贷款怎么申请

- 申请人：在校大学生、毕业 5 年以内高校毕业生、登记失业人员、退役军人、返乡农民工等重点群体，以及符合条件的小微企业。
- 经办路径：向户籍地或创业地人社部门（或其委托的经办机构）提交申请，通过审核后由合作担保机构提供担保、经办银行放款，财政给予贴息。
- 关键动作：先确认拟开户银行是否为创业担保贷款经办行；提前准备营业执照、经营场所证明、经营流水、身份与学历证明。
- 嘉兴设立了规模 1000 万元的就业创业贷款担保基金，为符合条件的贷款提供担保支持。

# 三、股权融资：BP 里投资人真正会看的六页

1. 你解决的问题是谁的问题，他现在花多少钱、多少时间解决它。
2. 你的解法与现有方案的差别，能不能被一句话说清。
3. 已经跑出来的数据：付费客户数、月收入、留存率、毛利率。
4. 单位经济模型：一单赚多少，多久回本。
5. 团队为什么是你们（行业经验、技术积累、独家资源）。
6. 这轮融多少钱、花在哪、能达成什么可验证的里程碑。

**不要写的东西**：市场规模千亿所以我们占 1% 就是十亿；对标某独角兽；三年后收入曲线拉直线上扬。

# 四、估值的粗算方法

早期项目常用两种方法：一是按融资额与出让比例倒推（融 200 万出让 10%，投前估值 1800 万）；二是按年收入倍数（SaaS 类 6—12 倍 ARR，服务类 1—3 倍收入）。学生项目在没有收入时，投前估值超过 2000 万很难谈成。出让比例建议控制在 10%—20%，一次让掉 30% 以上会严重影响后续融资。

# 五、可对接的本地资源类型

- 政府引导基金与国资平台参股的天使基金
- 孵化器与众创空间自带的种子资金和路演通道
- 银行的投贷联动、认股权贷款
- 浙江清华长三角研究院等新型研发机构的产业化基金与技术入股
- 各类创新创业大赛奖金与配套落地奖励（获奖后落地嘉兴常有额外奖励）
